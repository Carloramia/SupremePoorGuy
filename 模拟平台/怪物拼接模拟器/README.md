# 怪物拼接模拟器

浏览器端 2D 素材验证工具 v0.5。支持本地作品库、层级组拖拽和组合部件改名；新增躯干无自带连接点，修正蛇形标准模板连续连接。不包含物理、动画、战斗或在线协同。

## 本地作品与 Git 同步

推荐双击 `启动平台.cmd`（需要 Python 3），从 `http://127.0.0.1:8765/` 打开。点击顶部“作品库 / 保存”，填写作品名称，点击“保存作品”。磁盘文件写入本平台的 `作品库/*.work.json`，不是下载文件夹，也不是仅保存浏览器缓存。文件包含缩略图、内嵌素材、拼接关系和层级组。点击库中缩略图旁的“载入编辑”可继续修改；“保存作品”更新该作品，“另存新作品”创建独立文件。覆盖保存会在 `作品库/历史备份` 保留旧版本。

直接打开 index.html 也能用：先点击“选择作品目录”，在支持 File System Access 的浏览器里选择本平台的作品库文件夹并授权。目录授权不保证跨会话保留；重新打开后可能要重选。若不支持此接口，请使用本地服务版。作品单文件上限 64 MB，传统导入 JSON 仍为 15 MB。

通过 Git 同步整个平台和作品库即可；浏览器缓存及目录授权不会进入 Git，平台不会自动提交或推送。其他成员启动平台／选择同一作品库，再刷新作品库可查看更新。多人不要同时覆盖同一个作品文件，可另存并交由 Git 合并。

## 层级与名称

- 新建层级组时可命名为 1、2、3 或“后翼”“主体”等；名称是标签，实际前后由组在列表中的顺序决定，列表上方在前。
- 按住部件行拖入另一组，或拖到同组另一个部件前方排序；按住组标题拖动整个组。也可使用组的 ↑／↓ 按钮和右侧“部件所属层级组”下拉框。
- 单件旁“改名”或双击部件名称会打开平台内弹窗；右侧名称栏同样可用。部件显示名不改变素材文件名、原素材库名称或身体连接关系。
- 改名、分组和排序可撤销，并随作品保存、方案导出恢复。旧方案按原 z 值迁移到编号组，保留遮挡顺序；新的 z 值由组顺序决定，不再直接编辑。

## 主要操作：先布点，再挂素材

画布导航：左键拖动空白处平移视野，或按住鼠标中键从任意位置拖动；滚轮缩放，“居中显示”重新对准整只怪物。平移不改部件位置、不清除当前选择、不进入作品数据或撤销记录；左键拖动部件／连接点仍用于编辑。

1. 在画布的躯干上右键 → “在此新增连接点”，点就创建在右键位置。
2. 在连接点上右键 → 选择素材 → “挂接到此连接点”。点不预设为手、脚、翼或躯干，可挂任意类型，也可挂多个部件。
3. 在点上右键 → “删除连接点（保留部件）”，所挂部件原地解除连接；可撤销。也可只解除所挂部件而保留点。
4. 左键拖动连接点改变位置，相连部件跟随。不必先选中躯干才能右键它的点；点隐藏时先勾选“显示连接点”。

模板及旧缓存保留布点位置和已有挂接，但连接点统一不限定类型。右侧参数栏和数量控制为辅助操作，不必先把点指定为手或脚。

## 打开与使用

静态拼接可直接用 Chrome 或 Edge 打开 index.html，无需依赖；项目目录自动读写功能需要上面的本地 Python 服务。当前预览服务为 `http://127.0.0.1:8765/`，只监听本机，不向公网开放。

平台现归档于项目根目录下 `模拟平台/怪物拼接模拟器`，包含代码、文档、截图及 `tests`。旧本地入口已迁移；若旧页面仍有未导出的组合，请先在旧页面导出 JSON，再从新入口导入。

1. 选择人形（1 身、1 头、2 手、2 脚）、兽形（横向躯干、1 头、4 足）或蛇形（6 段连续躯干、1 头、无手脚）模板。模板替换当前组合但保留素材库，可撤销；旧缓存优先恢复，不强行套模板。
2. 调整左侧“躯干总数量”，新增躯干不带连接点、自由放置，不自动接成长链或改变模板类型。需要挂接时先在原躯干上右键布点，再向该点挂入躯干素材。选择某段躯干后，右侧可独立调整头、手、脚、翅膀数量，缺少接口时自动增点。减少躯干会移除其连接后代，操作前提示，可撤销。
3. 选素材类型，导入 PNG、JPG 或 WebP，点击“添加到组合”。躯干素材可增加新段；其它部件挂到所选躯干。右侧“连接到躯干”和“接口”可改挂，也可自由放置。推荐透明 PNG / WebP。
4. 选躯干可辅助编辑连接点名称、位置，或直接拖动画布上的点；所有点不限部件类型。删点会原地解除其部件连接，不删除素材。宽度、纵向比例和素材替换用于改变躯干外形；不提供自由绘制轮廓。
5. 在画布或组合列表选择组件，拖动微调；右侧调整宽度、纵向比例、旋转、翻转、前后层级。层级越大越靠前。修改素材锚点（0–1）可消除透明留白造成的错位。
6. “替换此素材”保留原接口、尺寸与前后层级；更换长宽比后请重新检查锚点。
7. “单独保存组件”导出一个 `.component.json`，包含图片和参数（躯干含自身连接点，但不打包所挂肢体）；“保存整只怪物”导出 `.monster.json`，包含所有素材、连接关系和记录。可导入 v0.1 方案，自动转为格式 v2；新版文件不能由旧平台读取。
8. “导出预览 PNG”生成透明底图，不包含连接点或选择框。复制躯干保留外观，但清空自身连接点、自由放置，不复制后代；导入已保存的组件则保留文件内明确保存的点位。删除组件会删除连接后代，多个部件时提示，可撤销。

v0.5 更新后请刷新页面，再点击“蛇形”重新套用标准模板，替换前有提示、可撤销。已有缓存和磁盘作品不会被自动改线。人形保留 1 身、1 头、2 手、2 脚；模板仅保留组成标准形态所必需的连接点，点位仍不限制所挂部件类型。蛇形首段接头、各段依次连接、末段无多余接口。

素材只由浏览器本机读取，不上传远程服务。自动保存是便利缓存，不是团队共享或可靠备份；不同浏览器、文件打开与 localhost 打开通常不共享缓存。及时导出 JSON 文件。文件选择上限 15 MB，组合最多 60 件；项目可能因累积大图超过导入上限，建议先压缩素材并保持导出的方案在 15 MB 内。

## 交接

- 参数和连接规则见 [构建逻辑.md](构建逻辑.md)。
- 平台代码变更见 [CHANGELOG.md](CHANGELOG.md)，接手修改时同步维护。
- 用户操作记录在页面“操作留痕与交接”中查看、导出；它记录拼接操作，不代替代码版本记录。
- 平台整体文件夹可以复制给团队；不需要修改游戏工程，未打开或修改美术讨论稿。
- 核心逻辑测试为 `tests/test_dynamic.cjs`。在平台目录内运行 `node tests/test_dynamic.cjs app.js`；无需安装依赖。旧 `test_core.cjs` 是 v0.1 历史测试，不用于新版验收。
- 数量控制：躯干 1–20 段，每段每类部件 0–10 件，每段连接点最多 40 个，组合总数仍为 60 件。
