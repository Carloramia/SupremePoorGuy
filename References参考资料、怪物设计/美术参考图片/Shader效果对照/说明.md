# Shader 效果概念对照

日期：2026年10月4日。使用内置图像生成工具，以同一张怪物底图分别编辑六种效果。每张左侧 BASE 为基准观感，右侧为单项效果示意。

这些是 AI 编辑概念图，不是 Godot 实际 shader 截图或逐像素滤镜实验；不同对照图的细节、尺度和排版存在轻微变化。底图来自此前立片对照图左上角怪物的清理版本，保留鸟首、羊角、狮身、红翼和蛇尾。素材尚未作为生产用透明贴图验收。

| --- | --- |
| [00 怪物底图](00_怪物底图.png) | 六种效果共用的输入参考。 |
| [01 统一外轮廓](01_统一外轮廓.png) | 整只怪物外围的连续深色描边，增强主体边界；不重复强化内部接缝。 |

当前建议先在游戏实际显示尺寸下比较 01 与 02 的辨识度，再少量加入 03 或 04。05 适合强化切纸感；06 展示贴片背后的偏移影，不代表战斗地面的真实投影或单位落点。

实际材质验证需保持完全相同的输入贴图、镜头、尺度与背景，分别开关单项效果，并检查移动时是否闪烁、多个部件是否重复描边、密集混战时是否仍能分辨单位。此阶段不据概念图判断性能。
