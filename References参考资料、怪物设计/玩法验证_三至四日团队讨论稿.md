# 三至四日基础玩法验证方案

状态：按用户最新范围修订，供团队执行前讨论。用户已明确本轮做三项：人形、兽形、蛇形标准生成及对应物理；大地图移动并进入战斗小地图；方块单位索敌与战斗。暂不需要击败后驯服。此前提出的六选三方案已移出本轮。

本文定义制作与验收范围，尚未实现原型或修改工程。本次不打开、不修改美术讨论稿，也不将美术效果制作排入日程。

## 最小验证单元

本轮由三个可独立运行的测试组成，地图和方块战斗在最后串联，物理怪物仍保留独立测试入口。

| 测试 | 最小内容 | 要回答的问题 |
| --- | --- | --- |
| 三类怪物与物理 | 选择人形、兽形或蛇形，生成标准结构，在简单测试场观察物理和受控移动 | 三类结构能否稳定生成、连接和行动？ |
| 大小地图切换 | 操作玩家标记移动，随时从当前位置进入关联小地图，再返回 | 位置、关联场景和往返状态能否正确衔接？ |
| 方块自动战斗 | 两阵营各三只方块，自动索敌、移动、攻击、受伤、退出和结算 | 战斗规则能否独立于怪物物理稳定运行？ |

首轮核心体验锚点：玩家能从大地图进入一场可读的自动战斗，同时团队能单独验证三类怪物的结构与物理。这是基础功能验证，不以此直接证明完整游戏的策略深度、成长或重玩乐趣。

## 三类标准生成与物理

“标准生成”的本轮建议含义是：先固定每类身体连接关系，只随机少量比例、尺寸或节段长度。三类必须能通过选项明确生成，不能依靠反复随机碰到相似轮廓。

| 类别 | 建议的标准结构 | 最小物理表现 |
| --- | --- | --- |
| 人形 | 一个头、明确躯干、两臂、两腿，默认左右对称 | 落地后结构保持连接；可向目标移动、转向、停止；肢体有受约束的物理响应。 |
| 兽形 | 一个头、水平躯干、四条支撑腿；尾部可暂省 | 四足结构可辨，能稳定移动和转向，受到轻微推力后不会整体炸开。 |
| 蛇形 | 一个头、建议五至八节连续身体、无腿；节数范围只是试样建议 | 前端引导移动和转向，身体节段随动、弯曲和碰撞，连接不持续拉开。 |

三类均使用方块、胶囊或现有占位部件。视觉分层只需帮助判断头、躯干和肢体，不要求正式怪物素材。

本轮物理范围为重力、基础地面碰撞、关节连接、有限转动、受控位移和轻微受力反馈。允许辅助保持姿态和引导移动；真实双足平衡、逼真四足步态、依靠摩擦推进的真实蛇行、复杂摔倒恢复、多怪物物理混战不作为本轮门槛。

物理测试中的推力用于检查稳定性，不接入战斗伤害。每次生成应显示类别和本次参数或编号，便于记录失败样本，不要求完整存档系统。

验收建议：每类连续生成十次，至少九次结构正确并能完成基本移动；对失败样本记录原因，不能只挑成功个体演示。每类至少一个标准样本完成三十秒静置、移动、转向、停止和一次轻推，无持续抖动、关节爆开、穿地或部件飞走。若需要辅助稳定，应在结果中说明。

## 大地图与战斗小地图

地图规则已按后续需求更新：大地图移动消耗时间、支持缩放，玩家随时可从当前位置进入小地图，不依赖固定入口；小地图布局与所在位置有关。探索不同难度地区的目的包括收集素材与关键阵眼引导物。详见[大地图探索与小地图关联策划案](大地图探索与小地图关联_策划案.md)。

原三至四日计划中的地图部分先作为基础往返测试：记录实际位置进入对应测试场，再返回原位置。位置关联至少用两种有明显区别的布局说明，不能将所有位置都送往同一无关房间；移动中进入时如何停止移动、退出条件等按新策划案的建议确认。

时间、缩放、完整区域探索和物品获取是新增需求，需要重新估算。原四天日程不自动包含全部新增内容。验收基础往返时，应在普通位置而非专设入口操作，连续往返五次无位置丢失或玩家重复生成。

## 方块索敌与自动战斗

方块是独立战斗单位，使用简化移动和碰撞，不调用物理怪物的关节、步态、断肢或部位伤害。怪物生成与方块战斗可以分别调试，不互相等待。

必需规则如下：

- 两个阵营，各三只方块，用明显颜色或标记区分。
- 首轮只做“最近有效敌人”一种索敌，取得目标后保持追击；目标退出或不可达时允许重新选择，避免不停切换。
- 只做一种近战攻击。进入攻击距离后按固定间隔造成伤害；无需让方块真实碰撞出伤害。
- 有可见生命或受损状态、攻击反馈和退出表现。生命归零后不可再成为目标，也不再攻击。
- 一方有效单位归零即结算；双方同时归零判平局。建议两分钟超时结束测试并记录卡点。
- 可重新开始，重置双方位置、生命、目标和计时；保留一个单独战斗测试入口。

先做一对一，再扩到三对三。低生命目标优先、远程攻击、技能、威胁值、编队、自由布阵和玩家战斗指令均为后续内容。

验收建议：连续十场三对三中，双方都能主动接敌、攻击并结束；目标退出后存活单位可以换目标；不攻击友军、无效对象或已经退出的单位。另测敌人为空时待机并正确结算，不要求不断报错或追逐不存在的目标。超时应作为待修问题记录，不算正常胜负通过。

## 操作与体验循环

基础验证的操作是选择测试类别与生成、在大地图移动并从当前位置进入小地图、观看战斗与重开。基础原型主要检查结构和交战关系是否可理解；后续新增的时间与探索资源取舍详见地图策划案，不在此预设策略已经验证通过。

| 操作 | 前提与触发 | 结果 |
| --- | --- | --- |
| 生成标准怪物 | 物理测试场选择类别并点击生成 | 获得该类受限随机结构，重置测试状态。 |
| 测试移动与受力 | 怪物生成完成后给出移动目标或轻推 | 观察转向、停止、连接及受力表现。 |
| 进入战斗地图 | 大地图玩家在当前位置主动进入 | 记录实际位置，进入与所在位置关联的小地图。 |
| 开始或重开方块战斗 | 战斗测试场点击开始或结算后重开 | 双方恢复初始状态并自动交战。 |
| 返回大地图 | 战斗结算后点击返回 | 恢复地点附近位置，等待下一次移动。 |

状态分别为：怪物生成 → 物理测试 → 重置；大地图移动或停留 → 主动进入当前位置小地图 → 返回；战斗准备 → 交战 → 胜负或超时 → 重开或返回。

```mermaid
flowchart LR
    A[观察 三类结构或战斗单位] --> B[决策 选择测试类别或地图地点]
    B --> C[行动 生成和移动 或进入战斗]
    C --> D[反馈 物理表现与自动战斗结果]
    D --> E[学习 记录问题并调整测试]
    E --> A
```

深度验证：本轮只验证行为可读与系统可复用，不设置熟练度提升或策略深度指标。重开用于排查稳定性，不等同于重玩价值。后续需要加入召唤选择、队伍或资源取舍，才能测试“是否愿意多玩一局”。

节奏验证：准备和观察不限时；建议自动战斗四十五至九十秒内结束，最长两分钟兜底。结算允许充分观察，再主动重开或返回，避免测试者被连续切图打断。

## 四天制作安排

按一名熟悉当前工程的程序每天约六小时有效制作时间，配合策划规则与测试支持估算。四天作为建议基准；三天只适用于已有功能经首日检查能直接复用，或有第二名程序并行承担地图与方块战斗的情况。

| 时间 | 当天重点 | 当天应能演示 |
| --- | --- | --- |
| 第一天 | 核对复用基础，建立三类标准结构与受限随机；优先排查蛇形无腿链式结构 | 明确选择类别后，三类都能连续生成，身体连接关系正确。 |
| 第二天 | 在独立场景完成三类碰撞、关节、辅助稳定及基本移动转向 | 三类各一例完成静置、移动、停止、转向和轻推；记录失败组合。 |
| 第三天 | 方块一对一到三对三自动战斗；余量内建立简单大地图移动与当前位置进入操作 | 方块能索敌、攻击、换目标和结算；大地图上玩家能移动并主动进入测试场。 |
| 第四天 | 接通大地图进入方块战斗地图、结算返回；完成重复测试、修正与交付 | 大小地图往返闭环，加独立三类物理测试入口；提供结果记录和可运行版本。 |

如有两名程序，第一名负责三类生成与物理，第二名负责方块战斗与地图，第三天可以串联并测试。此处仅是团队分工建议，不代表自动委派或新增人员。

每天至少预留一小时做当日验收。时间紧时依次删去装饰、额外随机参数、第二种场景外观、复杂地面和高级动作，保留三类、大小地图往返和方块战斗三项主目标。若某一类仍无法稳定运行，明确标记未完成并调整工期，不能以静态摆放或取消该类别宣称全部完成。

## 已知基础与工期风险

只读检查发现现有工程中已有 CreatureGenerator、GeneratedCreatureCharacter3D、NPCStateMachine3D、CharacterDamageController3D 等生成、移动、阵营与伤害相关内容，以及 TestLevel 测试场。这些是复用候选，本轮尚未运行检查。

现有生成器暴露多足、躯干、颈与头的配置，脚数配置下限为二；未确认它已支持无腿蛇形标准生成。现有 NPC 状态主要为待机与向目标移动，不能据此认定完整战斗已做好。因此，首日优先确认蛇形与三类基础行动，第三天独立检查方块战斗，避免将已存在脚本误计为已完成需求。

如果三类都要求真实物理驱动步态、自然平衡和复杂恢复，三至四天估算不成立。当前计划采用可受控移动、具有真实关节与碰撞反馈的最小版本，高级运动质量另行迭代。

## 最终交付与记录

交付三个可独立测试的入口，大小地图到方块战斗的完整往返，一份简短操作说明，以及验收记录。每条记录包含模块、类别或测试编号、操作、预期、实际结果、是否通过和待修问题。

通过结论分别写明：三类标准生成是否通过；三类基本物理是否通过；大小地图往返是否通过；方块索敌战斗是否通过。地图与方块战斗的串联不要求物理怪物投入实战。本轮不涉及美术最终定稿、shader 实装、驯服、寿命、出售和魔王终局。
