# 怪物形态分类团队讨论稿

更新日期：2026年10月4日。状态：已放入公共区供团队讨论，分类边界尚未全部定案。

本稿主要依据个人工作区的[怪物形态分类策划案 v0.1](Lworking%20document/02_怪物形态分类策划案_v0.1.md)，保留其“七种主形态＋修饰标签”框架。结合已明确的程序组合怪物、多单位自主索敌与攻击玩法，补充制作和讨论边界。本文用于统一策划、美术与程序的描述方式，不规定生成算法。

## 核心方案

每只怪物选择一个主形态，再添加构成关系、体型、组织关系和材质标签。主形态回答“整体首先像什么”，标签回答“怎样组成、有什么特殊属性”。分类以项目采用的具体形象为准，同一个神话名称可以对应不同设计。

**程序拼装是一种制作方式，不等于所有生成结果都归为拼接生物。**狮身替换尾巴后仍可能是兽形；只有多个来源权重接近、难以确认主导基础形态时，才按原案归入拼接生物。

## 七种主形态

| 主形态 | 原案定义要点 | 识别与制作关注点 |
| --- | --- | --- |
| 人形生物 | 以人的姿态、躯干和肢体关系为基础增减修改，人形仍是第一识别结果。 | 保留明确姿态与行为意图；如四臂巨人、兽首人。 |
| 兽形生物 | 以一种可辨认的动物为基础修改，包含兽、鸟、鱼、昆虫等。 | 基础动物与运动方式清楚；如主导兽形明确的狮鹫、雷鸟。 |
| 龙蛇形生物 | 修长连续躯干、盘绕、滑行或多节身体主导轮廓。 | 区分头、尾与身体走势；名称叫“龙”不自动决定分类。 |
| 拼接生物 | 多种生物部件重新组装，难以确认人形、兽形或龙蛇形主体。 | 可对称或不对称，但应有一个视觉重心；原案建议普通怪物最多三个主要部件来源。 |
| 无定形体 | 烟雾、液体、火焰、虫群等形成身体，缺乏固定实体解剖结构。 | 必须有稳定核心或视觉锚点；明确一个怪物与多个独立单位的区别。 |
| 异质具象体 | 植物、石头、尸骨、器物、机械或建筑形成稳定实体身体。 | 材料与构件影响运动、声音或破坏表现；与其他主形态的优先关系待讨论。 |
| 超越生物 | 身体首先服从几何、数字、符号或空间规则。 | 用一句话说明构成规则，仍需读懂危险方向；普通单位是否使用待讨论。 |

以上是游戏设计分类，不是神话学的物种归类。奇美拉、亚巴顿、天使等名称仅可作为具体版本的参考入口，不能代替设计图判断。

## 修饰标签

| 维度 | 候选标签 | 使用说明 |
| --- | --- | --- |
| 构成关系 | 复合、融合、骑乘、寄生、群体 | 复合表示多个完整类型并存；融合强调原独立身份共享身体；骑乘、寄生描述个体关系；群体表示多个小个体共同维持一个怪物身份。 |
| 体型 | 小型、常规、大型、巨物 | 原案以玩家尺度和空间影响判断；本项目的体型参照物需团队统一。巨物按原案应实际改变地图、镜头、移动或攻击规则。 |
| 组织关系 | 对称、不对称、环形、分支、递归、内外双层、可分离、可变形 | 描述身体组织方式。环形不自动等于递归，多头也不自动等于群体。 |
| 材质 | 血肉、骨骼、甲壳、植物、石质、金属或器物、火焰、烟雾、液体、阴影、虫群、混合材质 | 材质原则上补充外观；与异质具象体的边界需要统一。 |

因此，“巨物”和“复合”保留为跨类别标签：可以有兽形巨物、龙蛇形巨物，也可以有带骑乘关系的人兽复合单位。它们不单独替代主形态。

## 边界案例

| 设计 | 原案口径或讨论建议 | 需要看清的边界 |
| --- | --- | --- |
| 狮身加鹰翼 | 主体明确时归兽形。 | 原案示例加了复合标签，但定义强调完整类型并存；仅增添翅膀是否算复合，需统一。 |
| 猿面、虎肢、蛇尾权重接近 | 原案归拼接生物。 | 关键是没有主导基础形态，不是部件种类多就必然属于拼接。 |
| 半人马 | 原案示例按马体承担移动归兽形，并加复合、融合。 | 原案也允许按视觉重心归人形；默认依据尚待确定。 |
| 独立骑手与坐骑 | 主形态描述主要战斗轮廓，增加复合、骑乘。 | 分类不直接决定它们是一个战斗单位还是两个，需要另行说明。 |
| 轮廓固定的烟雾蛇 | 原案归龙蛇形，增加烟雾材质。 | 固定长躯与没有稳定轮廓的烟云不同；材质不直接决定主形态。 |
| 无固定轮廓的追踪烟云 | 原案归无定形体。 | 原案示例同时标群体；建议仅在多个小个体共同构成时使用群体标签。 |
| 石质人形与会行走的城堡 | 原案判断流程优先归异质具象体。 | 石质人形也符合人形轮廓定义，需明确材料优先还是轮廓优先。 |
| 同心轮与眼构成的生命 | 几何规则主导时归超越生物。 | 递归标签只用于存在重复嵌套规则的设计，不能仅因有多层轮就使用。 |

## 与当前美术及战斗方向的衔接

分类用于指导主体、部件差异和行为表达，不要求每种形态采用不同画风。统一使用当前[美术方向与参考](美术方向与参考_团队同步.md)中的粗轮廓拼接立片、关节纸偶和低对比战场建议。

允许身体、尾部和手脚不完全连贯，通过统一连接件和遮挡关系表达装配感；同时保证单只怪物的主体、视觉中心和朝向可辨。阵营底圈独立于主形态和材质，避免依赖怪物颜色判断敌我。

原案关于长躯占地、材料破坏、弱点暴露等内容属于设计方向，不自动成为已承诺的战斗机制。是否影响碰撞、索敌或攻击范围，由团队结合实际玩法确认。

## 首轮试样与设计卡

原案建议七类各选一个差异明显的设计，先验证分类是否能指导制作。巨物和复杂复合生物先做轮廓或概念验证，不进入第一轮批量制作；这是讨论建议，尚未形成排期。

每只试样用一张简卡记录：

- 名称与参考图或来源；主形态；必要的修饰标签。
- 第一眼轮廓；标志性异常部位；必须保留和可删减的特征。
- 移动与标志动作；攻击表达；弱点或代价（如适用）。
- 必需部件、动画与特效；可复用内容；当前不做的内容。
- 讨论状态与尚未解决的问题。

验收时按实际战斗镜头缩小观察，并检查混战遮挡：能否分清单位、阵营、朝向及攻击反馈，部件组合后是否仍符合所选主形态。

## 本次团队需要讨论的决定

1. 是否采用七种主形态与修饰标签框架；项目是否实际制作植物、器物和建筑生命。
2. 异质具象体是否保留为独立主形态，以及它与人形、兽形、龙蛇形的优先关系。
3. 主形态判断优先看视觉重心还是移动主体；以半人马和狮鹫作为共同测试例。
4. 复合标签是否仅表示完整类型并存；局部换头、加翼等是否只记部件与材质。
5. 超越生物是否限于稀有怪、领主和 Boss；巨物是否必须影响战场规则；体型以什么对象为参照。
6. 第一轮要验证哪些类别与多少部件，哪些先保留为概念；由原型结果决定扩充顺序。

策划负责定义、例子和验收，美术负责形态表达与部件统一，程序负责组合和战斗实现。本稿作为公共讨论入口，完整过程资料继续保存在个人工作区。
