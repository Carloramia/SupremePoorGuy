# 怪物分类团队同步

## 当前工作边界

- 策划定义体验、分类、行为差异、组合边界、优先级和验收标准。
- 生成算法、代码结构、资源加载和性能方案由程序决定；策划只提出简单约束建议。
- 完整过程稿位于 `Lworking document`。本文件只保留团队当前需要执行的内容。

## 怪物分类

每只怪物使用以下五项描述：

`主结构类别 + 活动介质 + 标志动作 + 战斗角色 + 代价`

主结构类别包括单体异兽、嵌合兽、增生异兽、融合体、无定形体和巨像环境体。首轮原型只做前四类。

## 首轮原型范围

先验证四种行为差异：

1. 冲锋型追猎者。
2. 尾部抓取的水域伏击者。
3. 使用叫声制造错误目标的干扰者。
4. 首尾均可攻击的反击型守卫者。

每只怪物只设置一个主要轮廓特征、一个标志动作和一个明确代价。神话形象用于提供结构和行为参考，随机普通怪使用项目自有名称，不直接使用神话专名。

## 团队待确认

- 首轮战斗是否需要水域环境；如果不需要，将拖拽怪改为地面钩锁型。
- 声音干扰是生成假目标，还是短暂改变索敌优先级。
- 首轮是否允许融合体；若美术成本过高，融合体延后。
