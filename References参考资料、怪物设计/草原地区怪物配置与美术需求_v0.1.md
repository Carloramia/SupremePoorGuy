# 草原地区怪物美术需求

版本：v0.1  
日期：2026-10-17  
状态：工作中  
适用对象：策划、美术与怪物素材制作成员

草原地区采用普通 A、普通 B、普通 C、精英 A、精英 B、Boss 六个分组位置，共九个怪物条目：八个普通／精英条目与一个 Boss 条目。甲狼与草狼是同一狼原型的变体；魔眼拱兽可仅替换普通拱兽头部；龙牙兵系列以异形头部为重点，身体可以复用普通骷髅兵方向。因此九个条目不等于九套独立原型。

亡灵羊的三名弓箭手已确定在背上搭乘，每节身体一名；厚草皮护甲覆盖背部和侧腹，分前、中、后三段，本体与护甲分开制作后拼接。狼的覆盖图层、普通／魔眼拱兽换头、龙牙兵异形头和大型素材精细度分别维护。食矿鸟、巨鼠没有额外造型限制，可以自由发挥。

本稿仅定义形象、构图、体型关系、原型复用、素材分层与美术交付，不确定攻击规则、伤害、护甲机制、受击死亡、胜负判定、遭遇投放或生成算法。已有动作与生态描述只用于指导形象和姿态。地图原生怪物的类型与外观应与玩家生成怪物有所区别。

## 已确认的美术安排

1. **Boss组合：** 三名龙牙弓箭手在羊背上搭乘，前、中、后三节身体各一名，保留各自轮廓；不再按后方跟随或身体融合出图。
2. **护甲覆盖与分段：** 主要覆盖背部与侧腹；头和六条腿以裸露骸骨为主。护甲分前、中、后三段，随对应身体活动。泥浆与布条先并入各段护甲，布条按固定装饰表现，不要求真实布料模拟。
3. **体型与素材规格：** 以中型狼为参照，拱兽突出高度，亡灵羊突出长度；根据实际战斗镜头确认最大显示尺寸，再确定源素材像素。没有具体镜头和尺寸输入时，不固定数值比例、像素或通用观察角度。
4. **龙牙兵首版装备：** 一款单手近战武器与弓箭两种装备方向，共用身体；异形头部由美术给出少量候选后选择。具体武器形制不在本轮强行扩展为多个武器种类。

## 普通怪需求

### 普通 A组

甲狼和草狼是同一种狼的两个变体，以同一个中型狼原型增加或更换外观覆盖图层表现复用。二者的主体比例、基础结构与姿态基准应保持一致，不分别重设计为两种狼。

- **甲狼必须保留：** 头部覆盖岩石状灰色甲壳，身体附带灰色石头外壳。甲壳和石头覆盖需要有实际形状与厚薄关系，不能仅把皮毛染灰；不替换成未经要求的金属头盔。
- **草狼必须保留：** 头部与身上单纯覆盖灰绿色皮草，不额外添加石壳。此处已由初稿的“草皮”细化为“灰绿色皮草”，不强制画成植物草坪、叶片披风或长草背甲。
- **复用交付：** 保留共用狼原型、甲狼头部覆盖层、甲狼身体石壳覆盖层及草狼灰绿色皮草表现。具体拆为哪些图片由素材结构决定，但共用原型和差异覆盖应可单独检查、替换。
- **对齐要求：** 使用相同镜头、比例和姿态比较两种外观；覆盖图层须与对应头、身及活动部位对齐，不能用一张不随部位活动的大贴片盖住整只狼。
- **素材边界：** 本次只交付外观覆盖，不规定两种狼的防御数值或石壳破坏机制。扑击、咬击作为姿态参考保留。

### 普通 B组

本组同时包含大型地面单位和飞行单位，主要差异来自支撑结构、活动高度与身体轮廓，不要求两者属于同一族种。

- **拱兽必须保留：** 大型四足行走动物，类似大象，外形参考《星球大战》的 AT-AT；头部短小、没有眼睛，只有一张用于进食的嘴。踩踏作为形象和足部动作参考。
- **参考转译建议：** 借鉴架高躯干、承重腿和头颈的整体轮廓与比例；普通拱兽仍以短小无眼头部为准。不自动继承参考载具的武器、标识或尺寸。具体材质由美术转译。
- **官方参考入口：** [Star Wars Databank 的 AT-AT Walker](https://www.starwars.com/databank/at-at-walker)，仅作外形参考，不替代本项目头部与足数要求。
- **食矿鸟保留：** 飞行，以及俯冲凿碎矿石并取食的生态行为。除此之外造型可自由发挥，不预设颜色、冠羽、喙形、额外器官或精确体型。
- 俯冲凿矿是生态与姿态参考，不在美术稿中定义矿石破坏或对敌攻击规则。

### 普通 C组

- **巨鼠必须保留：** 小型、爬行、群体出现，主要依靠咬造成伤害。
- **造型自由：** 没有额外要求，可自由发挥；不预设甲壳、背刺、毒牙、特殊毛色或附加技能。
- “巨鼠”为当前名称；战斗尺度仍按小型记录，不能仅因名字自动生成大型单位。“爬行”描述移动方式，不将其改成爬行动物。
- 本批先出完整单体，保留小型群居的观感；实际群体数量和单位判定不属于本稿。

## 精英怪需求

### 精英 A组

龙牙兵系列的设计核心是异形头部，其余部位可以仿照普通骷髅兵。龙牙兵与龙牙弓箭手可共用普通骷髅身体方向，以装备和攻击姿态区分；不要求每个身体部位都重新异形化。

- **龙牙兵必须保留：** 类人形骨架、骷髅材质、手持一款单手近战武器，异形头部承担主要识别。可探索蛇头、龙头或其他异形头部，不强制使用普通人类头骨。
- **龙牙弓箭手必须保留：** 人形骷髅身体、手持弓箭，并沿用异形头部的族群方向。持弓、拉弦与瞄准方向应可辨认。
- **美术重点：** 优先检查头部的独特轮廓，其次检查装备；普通骷髅躯干和四肢不需要增加同等密度的装饰来争夺视觉中心。
- **制作边界：** 异形头部先出少量候选，不自动开放任意生物部件随机拼接。头部、单手武器、弓箭与共用骷髅身体分别保留可替换边界，具体细分数量由实际素材方案确定。

### 精英 B组

- **魔眼拱兽必须保留：** 以普通拱兽为基础，替换为具备巨大眼睛、能够发射光波的头部。普通拱兽头部无眼，魔眼头部则以巨大眼睛建立明确区别。
- **最小改动方案：** 可以只替换头部，躯干、四条腿、比例及其他外观完全不变；优先按这一方案验证复用，不要求为精英额外重做身体。也允许增加外观纹路，若采用应单独保留纹路层。
- 替换头部须保持与共用躯干的连接位置、比例与活动关系一致。巨大眼睛和光波发射方向应可辨认；具体眼睛数量和其余头部形状仍可设计。
- 本稿只要求巨大眼睛和发射方向在外形上可读，不确定单眼／多眼数量、光波攻击形式、预警、冷却或攻击切换规则。

## Boss需求

### 浑浊大地亡灵之羊

本体为大型亡灵羊，身体分为三节，每节各有两条腿，合计六条腿。所有裸露部分都呈骷髅状；外层披着类似草狼草皮的护甲，并增加泥浆与布条使其显得更厚；三名龙牙弓箭手在羊背上搭乘，每节身体一名。大型尺度、三节身体、每节两腿、裸露骸骨、厚草皮护甲与三名骑乘弓箭手是必要组成。本体与护甲必须分开制作，最终拼接，不画死在同一张不可分离的整体素材中。

**美术必须保留：**

- 羊的主体识别，不因为骷髅、草皮或弓箭手遮挡而变成无法辨认的混合体。
- 三节身体的先后关系与连接，每节明确对应两条腿，不能只有外表画出三道分割线、实际仍是一个四足羊身。
- 六足支撑关系，以及所有裸露部位的骷髅表现。头、颈、身体连接与腿部等可见处不能误画为正常皮肉；草皮覆盖部分仍保留覆盖层关系。
- 前、中、后三节各搭乘一名弓箭手，三人保留各自轮廓、持弓方向和搭乘支撑关系，不将其误生成为一名、多头个体或纯装饰骨架。骑手不与羊体融合成一组新增肢体。

**本体与护甲分开制作：**

- **本体：** 以三节骷髅羊身、头颈与六条腿为结构基础。护甲覆盖下的关节和运动时可能露出的部位需要保留足够完整的骨性结构，不能因静态遮挡直接挖空。
- **护甲：** 以类似草狼的草皮／皮草表现为基础，增加泥浆堆积与布条包覆来表现厚度和重量，主要覆盖背部与侧腹；头部和六条腿以裸露骸骨为主。灰绿色皮草是现有草狼的基准，可作为护甲底层参考；泥浆和布条不能仅退化成一层脏色滤镜。
- **拼接：** 本体和护甲使用一致的镜头、尺度、姿态与对齐基准，提供裸本体、独立护甲及组合预览。护甲轮廓要让三节主体与六足关系仍可读。
- **已确认拆分：** 护甲按前、中、后三段随对应身体分开，避免一整块外壳跨过所有活动连接。泥浆与布条先并入各段护甲，布条按固定装饰表现，不要求每条布独立制作或真实布料模拟。每段护甲需要保留对应骑手的落座与遮挡空间。
- **范围：** 本体／护甲分离是美术交付要求，不确定护甲的游戏机制，也不因此追加破损或脱甲阶段素材。

**大型素材精细度：**

- 按游戏中预计最大的显示尺寸检查主体、头部、三节身体连接、骨骼和六条腿，不能将普通怪物的小图直接放大充当 Boss。具体显示尺寸未定前，不预设固定 2K／4K 等像素规格。
- 大轮廓、骨架组织与局部材质分层处理：近看能辨认颅骨、肋骨或骨性连接及草皮边缘，远看仍先读出羊体、三节和六足。不能用密集裂纹、颗粒或细线代替结构精细度。
- 三节连接处、肢体根部和草皮遮挡边缘要留出运动所需的完整结构，避免活动时露出空洞、截断骨骼或分辨率不足的接缝。需要遮挡补绘的范围由实际部件方案确定。
- 推荐保留分层源稿与各节可独立检查的部件素材，同时提供完整组合预览。具体拆件数量、透明边和源图尺寸待显示尺度与动画方案确定，不能从概念图直接认定已可生产。

**体型与骑手复用：**

亡灵羊突出修长的三节羊身，拱兽突出架高，狼作为中型比例参照；精确尺寸随实机镜头标定。三名骑手沿用龙牙弓箭手方向，不另计三种新物种；以合适比例调整为背上搭乘姿态，能否直接复用现有素材仍需对齐检查。

Boss的具体攻击、受击、死亡及胜负判定留到具体制作时讨论，本稿不采用此前的战斗建议。

## 差异化与生成边界

以下为制作建议，不额外确认新技能：

| 对照对象 | 应优先拉开的差异 |
| --- | --- |
| 普通 A 与普通 B | 中型狼状单位，对比大型架高单位与飞行单位 |
| 普通 C 与普通 A | 小型贴地鼠群，对比中型狼状个体；数量感不能只靠画面缩放冒充 |
| 精英 A 与精英 B | 持武器的类人骷髅，对比大型巨眼拱兽 |
| 甲狼与草狼 | 同一狼原型的头部及身体岩石覆盖，对比单纯灰绿色皮草；不靠改骨架制造差异 |
| 普通拱兽与魔眼拱兽 | 身体可完全不变，普通无眼头对比巨大眼睛与光波发射头 |
| 龙牙兵与弓箭手 | 共享异形头部与普通骷髅身体方向，通过装备、上肢姿态和攻击方向区分 |
| Boss与普通怪 | 大型三节六足骷髅羊、草皮与三弓箭手组合，而非普通拱兽单纯放大 |

地图怪物与玩家生成怪物共用项目美术语言，但建议采用稳定的类型识别和有限变体，不套用任意异质拼接。不能仅靠颜色、铜钉或有无白边区分敌我；阵营标识仍应独立于怪物本体。

AI生成时，一次先验证一个完整个体。普通群体的遭遇数量与单体设计分开；Boss可先出组合概念，再根据确认的关系深化素材。全身、头部或朝向、主要攻击端、实际脚点／飞行中心应清楚；不得将场景、卡框、文字或固定阵营标记烘焙进战斗单位。
