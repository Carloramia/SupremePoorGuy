# 怪物自动战斗美术方向与参考

更新日期：2026年10月4日。面向策划、美术和程序成员，汇总当前讨论后的推荐方向，作为制作试样的共同依据。本文已同步到公共区；最终画风与实现效果仍需团队通过战斗原型确认。

## 当前方向

**以粗轮廓、有限配色的拼接立片和关节纸偶表现怪物，以低对比场景承载多单位自动战斗。**角色画法参考套色木刻的简洁色块；纸剧场的层次、遮挡和投影主要用于场景边缘与召唤演出。

项目的关键条件是：美术素材主要由 AI 生成；怪物身体、头、手脚和尾部由程序组合，形态可能不连贯；敌我多个怪物会同时自主索敌和攻击。因此，当前优先级为：单位与阵营可辨认、攻击方向和反馈清楚、部件组合风格统一，最后才是装饰细节。

“术士装配的神话造物”是建议采用的视觉解释：允许异质肢体、不对称比例和显露的连接件。这是美术表达建议，尚未作为新增世界观设定确认。

## 怪物造型要求

| 内容 | 当前要求 |
| --- | --- |
| 身体 | 保留一块完整的大色块和稳定的视觉中心，重叠时仍能识别单只怪物。 |
| 头部 | 头、眼睛或核心应明确表达朝向。几何与无定形生物也需要可追踪的焦点。 |
| 手脚与尾翼 | 根部允许由身体或连接件遮挡，末端简洁；附属部分的细节弱于身体。 |
| 接缝 | 选用少量统一的套环、铆钉、缝合片或局部烟雾。保留有意的错位，避免方向错误、部件全部重叠等结构问题。 |
| 线条与材质 | 外轮廓强、内部线条少；使用有限色块、轻微干笔与纸纹。避免所有小部件都重复粗描边。 |
| 动作 | 优先表达身体前倾、头部啄击、肢体摆动和短促受击。待机轻微，攻击起手与命中清楚。 |

描边、纸纹、切边磨损和浅投影可由统一材质效果辅助。策划规定最终观感；具体 shader、遮罩和节点组织由程序与美术验证。边缘效果保持稳定，避免运动时闪烁；烟雾和火焰允许断续轮廓，不强制使用实体怪物的完整黑边。

## 多单位战斗要求

- 阵营标识独立于怪物种类和身体颜色。当前试样使用青色圆圈与珊瑚红六边形，颜色和形状共同区分；具体配色可在原型中调整。
- 底圈与落地阴影明确单位中心。长尾、翼和烟雾属于外观延伸，不应让玩家误判站位。
- 头部朝向、转身和短暂起手表达索敌及攻击意图。建议仅选中单位显示目标连线，避免全场连线遮挡。
- 优先保证攻击起手、弹道、命中和受击的清楚程度；普通攻击特效克制，危险攻击可更突出。
- 战斗区域保持低对比和较少细节；纸剧场装饰集中在外围，避免遮挡单位与攻击信息。

## AI 素材制作流程

先为站立、四足、长躯和悬浮等主体确定少量试样，再围绕它们制作部件。每组统一视角、光线、轮廓粗细、色彩范围和部件相对尺度；AI 候选图经筛选、结构修整和风格统一后进入素材库。

先用少量素材组合验证，再增加数量。验收重点是实际游戏尺寸下的轮廓、接缝、遮挡与动作，不能只检查单张高清立绘。统一后处理可改善呈现，但不能代替结构修整。

## 下一步验收与分工

用团队目标镜头和实际显示尺寸测试多种部件组合，覆盖靠拢混战、相互遮挡、远程攻击及无定形怪物。首先检查能否分清单只单位、所属阵营、朝向和攻击反馈；再检查接缝是否显得有意、不同素材是否属于同一视觉体系。

策划负责体验要求、分类边界和验收；美术负责造型、部件修整与风格统一；程序负责组合、动作与显示实现。最大同屏数量、镜头距离、最终色板、连接件形式和材质效果仍待原型确认。
