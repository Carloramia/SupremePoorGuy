# Lworking document

本目录存放策划侧的过程稿、长文档、调研记录、候选方案和未定内容。默认不要求团队成员持续阅读。

只有已经压缩为团队执行所需的最少信息，才会单独同步到上一级 `References参考资料、怪物设计` 目录。外层文件不得包含大段调研过程、程序实现细节或尚未收敛的候选方案。

- `00_工作边界.md`：策划职责和团队同步边界。
- `01_神话生物分类与整合流程.md`：当前怪物分类方案、整合步骤和示例。
- `research/`：资料来源、比较过程、筛选记录和研究决定。
- [涌现召唤战斗与妖兽仓库整合策划案 v0.2](涌现_召唤战斗与妖兽仓库整合策划案_v0.2.md)：2026年10月14日整合，区分已确认规则、测试数值提案与待定事项，包含符文图形、畸变、实时群战、永久死亡、条件回收和书页仓库需求。
