# 神话怪物设计分类与策划案重构研究

## 研究目标

重整并补充“疯狂魔法师召唤”策划案，建立适合随机生成怪物的分类逻辑，并筛选一批有一定公共认知、但尚未在游戏中高度俗套化的神话怪物形象作为视觉与行为参考。

## 领域与交付物

- 领域：Game Jam 游戏机制、程序化怪物生成、神话视觉研究。
- 最终交付：新版中文 DOCX 策划案。
- 受众：程序、美术、策划与音频成员。

## 范围

- 保留第一方案的核心：召唤、随机组合、击败后驯服、寿命、出售和魔王终局。
- 补足核心体验、挑战模型、观察决策反馈循环、怪物生成语法、数据结构、MVP 数值、验收标准和制作切分。
- 神话怪物只作为形态语法、器官、材质、行为和生态的参考，不直接复制宗教叙事或专有角色。

## 非目标

- 不吸收第二方案“尤里卡时刻”的主机制。
- 不建立大型固定图鉴。
- 不在本轮制作怪物概念图或游戏实现。

## 主要风险

- 来源误读或把现代二手形象误当作原始神话。
- 参考对象太冷门，玩家无法形成联想；或太常见，失去新鲜感。
- 文化语境敏感，直接商品化仍在实践中的信仰对象。
- 分类只服务世界观，不足以驱动程序生成和战斗行为。
