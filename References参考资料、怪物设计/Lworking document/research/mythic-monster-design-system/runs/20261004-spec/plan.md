# Specify 计划

- Phase: Specify
- Inputs: 第一方案、公开博物馆和学术图像资料、Game Jam 约束。
- Output: 可直接写入策划案的分类系统、候选参考库和 MVP 参数。
- Evidence tiers: 博物馆或研究机构页面优先；历史原始记录次之；汇总资料只用于交叉检查。
- Metrics: 轮廓辨识度、部件可拆性、行为可映射性、公众认知、俗套风险、文化使用风险，每项 1 至 5。
- Edge cases: 同一神话存在多种形象；神祇不是普通怪物；活态信仰对象不可直接商品化；冷门对象认知不足。
- Validation: 每个主候选至少能提取一个轮廓钩子、一个行为钩子和一个可实现的战斗标签。
