# A · 巡游画师工作台：分件与效果测试

历史测试版本：当前运行已切换为纸雕UI，见 [当前美术指导与格式](03_纸雕UI_美术指导与素材格式.md)。本页保留上一版青绿水粉A测试记录，不作为当前配色和切片规范。

## 基础信息

类型：UI、材质、动画；优先级S为公共纸底／按钮／分件接口，A为画框装饰与动效。用户已选择A，并要求贴图分割以便后换美术。本轮为效果验证，没有另定制作期限；不修改正式工程、网页召唤或其他成员正在编辑的美术稿。

设计目标：以画板、夹纸、墨线与青绿水粉建立旅途记录感。正文区保持明亮清楚，主操作用笔刷色块，属性用较轻纸签。主要系统打开时整块画板滑入，关闭时横向移走；内部文字、法阵和命中区落位后稳定。日常列表与嵌套说明不重复播放全板动画。

screen_id：UI_MAIN_WORLD、UI_POPUP_RITUAL、UI_POPUP_WAREHOUSE。父界面大地图；书本打开召唤，顶栏打开仓库，返回按弹窗栈逐层关闭。没有增加进入小地图的步骤。

## 主体、构图与风格

正面、平面、浅层构图；木框窄边，不做写实厚木板。纸黄#EEE2C8、墨#263B3B、青绿#376F68、铜#BC8942。只有纸纹和受控毛边，不在正文中心加污渍、伪文字或神秘图样。本项目A提案为风格来源；不复制参考游戏贴图。

纸、木框和按钮底是三次分别生成的独立PNG。木框中心与外围均透明；夹子、铜钉使用独立SVG。当前怪物、地图、法阵与喷涌继续是原型占位／原生绘制，不属于这次生成的美术资产。

## 功能与动画约束

- 必须/MUST：当/WHEN 换木框，则/THEN 只替换WoodFrame纹理，且/AND 纸底、文字、法阵规则与怪物图不变。
- 必须/MUST：当/WHEN 画板滑动，则/THEN 只移动外层MotionRoot，且/AND 不缩放窗口或重新排布阵面。
- 必须/MUST：当/WHEN 动画进行，则/THEN 屏蔽键鼠输入与底层按钮，且/AND 完成后恢复焦点与原禁用状态。
- 必须/MUST：当/WHEN 跳过演出或简化动效，则/THEN 同一批产出只保存一次，且/AND 不再次生成／扣费。
- 必须/MUST：当/WHEN 连续关闭重开，则/THEN 取消旧动画，且/AND 不能让延迟结束把新面板关掉。
- 应该/SHOULD：当/WHEN 更新列表或打开嵌套说明，则/THEN 不重播整块画板长动画。

| 动作 | 当前试做值 | 可编辑入口 |
|---|---|---|
| 画板从下方进入，轻微落位 | 0.30秒，Y 760 → -5 → 0 | BoardMotion.tscn / AnimationPlayer / enter |
| 画板向右移开 | 0.22秒，X 0 → 1320 | 同上 / exit |
| 内部详情、术语与筛选刷新 | 不播放全板动效 | 现有弹窗栈与组件 |
| 召唤业务切到喷涌 | 瞬时关闭面板，沿用2.8秒喷涌 | 不等待装饰动画再保存 |
| 简化动效 | GameDemo的Animate Panels关闭 | 编辑器脚本属性；原型尚无玩家设置页 |

本轮没有实现幕布、翻书骨骼动画、真实布料或主场景剧场换景；B／C仍保留为历史候选，不混入A。

## 验证与证据

运行入口为GameDemo，效果来自真实Godot渲染，不是静态整页概念图。

- ValidateNativeUI：257项，0失败。
- ValidateUILayout：436项，0失败；六种物理窗口，设计空间阵面368×368。
- ValidateArtUI：30项，0失败；覆盖输入隔断、取消旧动效、无缩放、嵌套返回、分件素材、简化动效、一次产出和安置。
- 结果页首屏主操作露出问题已修复：属性独立为紧凑StatButton，主操作仍为青绿笔刷按钮。
- Tests/screenshots：9个流程状态；Tests/previews/A_workbench_v1.mp4为自动演示视频。
- Tests/RecordArtTest.gd可复现自动演示，使用独立native_art_capture存档，不操作个人正式进度。
- 这些是原型回归，不是正式地图、真实战斗或最终美术的验收。

当前风险：笔刷母版边缘仍偏丰富；正式美术可重画为更克制的笔触。不要每个界面单独随机生成纸底和按钮，先替换共用母版。环境地图、纸偶角色及喷涌需要后续生产资产；本次重点是分件结构、统一性和动效能否成立。

验收清单：纸／框／铜钉／按钮分开；文字与数值不烘焙；中心透明；装饰不拦输入；法阵落位不变；切片可修改；快速开关无残留；保存不依赖动效；交接索引可查。以上已做原型检查，视觉喜好仍待用户确认。
