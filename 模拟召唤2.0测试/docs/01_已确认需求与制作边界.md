# 0.6召唤与仓库试验边界

本独立副本根据用户2026-10-14的要求实现召唤与仓库交互试验。旧0.5内容保留在原工作目录，不回写覆盖。

已确认方向：法阵7/19/37/61格，剧情/Boss解锁；法阵与妖兽等段分开，无额外付款提段；符文与奇物按格同价；普通5只；基础/强化/最强同款畸变门槛4/3/2；畸变强化触发源；巨化3只各2位、超巨化1只5位、縮小每5只1位；分身及缩小不可回收；生成后不能永久成长；胜利只回收本场己方战死本体的等段-1魔力；仓库左列表右详情。

本轮不把尚未定案的数值当作正式规则。试验概率、倍率、门槛、队位上限、整组安置与演示配方集中列于[本次指南](05_召唤仓库调整与回退.md)。结构混用保留设计，但暂拒绝未定义的组合并提示。

界面沿用原有地图入口、喷涌和原生组件。剧情解锁使用明确命名的模拟按钮；实际剧情事件未接入。真实战斗及分身、护盾、灼烧、击杀治疗未接入。部分战斗能力仅记录属性和说明，不能声称具有实际交战表现。

战斗回执接口负责永久移除与条件回收，可独立验证，但跳过战斗仍保持旧测试奖励，不伪造战斗结果。

所有生成、安置、改名、编队、解锁与结算必须遵守存档失败回滚。pending恢复同一实例，不重新生成。仓库详情以唯一ID关联，筛选空结果不保留错误个体，能力返回恢复筛选、所选和阅读位置。

所有概率数值都应显式标注试验；只有可能畸变时显示风险UI，出现风险不挤动阵面。六尺寸布局、输入隔断和底层组件设置继续回归。
