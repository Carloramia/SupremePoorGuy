Godot 4.7.2 · 用户试玩确认后的独立测试工程 · 2026-10-14。

导入本目录project.godot，确认工程名称为“涌现 · 模拟召唤2.0测试”，F5运行。GDScript工程，不需要C#/.NET。

**先看 [本次实现、试玩步骤、试验参数与回退](docs/05_召唤仓库调整与回退.md)。**

真实战斗、分身入场与畸变外观未接入；概率、等段门槛、队位上限、结构组合与倍率均标为试验参数。旧0.5和主工程不受本试验覆盖。

仓库搜索、筛选、排序、选择、改名、编队与说明返回可测试；结果先保存再演出，存档失败整笔回滚。战斗回执接口可验证永久死亡与条件回收，但跳过战斗不调用它。
