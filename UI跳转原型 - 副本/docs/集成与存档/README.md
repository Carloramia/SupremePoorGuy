先确定唯一状态服务与唯一场景切换负责人，再接各模块。GameDemo和PrototypeState是共享文件；现有信号不能取消测试分支，也不存在已完成的通用宿主适配器。

准备映射表：正式服务方法→原型调用点→输入字段→成功／失败回执→幂等ID→保存／恢复责任。先接只读快照，再接动作请求。魔力、怪物、队列、pending、事件进度和奖励账本不得各系统各存一份。

原型有独立user目录与备份，正式接入不能覆盖主project.godot或沿用测试随机生成。主工程声明C#／Forward Plus、不同窗口stretch和Autoload，须在主工程环境重新验收。迁移资源需统一重写res://路径并核对.uid/.import。

最低回归：依赖完整、无双路切景、按ID转移、事务失败回滚、请求去重、重启恢复、跨版本迁移、六种窗口／输入隔离。只有宿主联调通过后才能宣布正式接入；原型测试不能替代真实模块测试。
