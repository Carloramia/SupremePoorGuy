## 与最新main重叠的接口

main新增了`FrontierEditor_20261019`、`HexWorldScene/HexWorldNavigation/HexWorldFog`地图实现、`SummonBattleStage3D`召唤演出及`WorldTimeSettings/WorldTimeHUD`等时间功能。本分支使用`HexFrontier_20261019`和`HexMapBridge`承载已批准的事件地图，两套实现不能直接覆盖替换。

| 双方修改的文件 | 合并需要处理的内容 |
| --- | --- |
| `Scripts/Application/GameRoot.gd` | 地图后端选择、场景生命周期、召唤演出、事件控制器、弹窗视口与战斗恢复 |
| `Scripts/Application/GameSession.gd` | main的时间/地图存档与本分支的事件状态、移动日历、奖励事务及物理快照 |
| `Scripts/Application/GameUIController.gd` | main新增UI与旅途待办、地图输入阻断、事件路由共存 |
| `Scripts/Application/CreatureFactory.gd` | 两边的实际物理模板与生成接口，保留鸟鼠、双头与魔眼记录 |
| `Scripts/Application/DeliveryMapBridge.gd` | main地图更新与事件抵达转发的兼容 |
| `Scripts/Creatures/PhysicalBodyParts.gd` | 保留main物理修复，同时保留本分支的跨世界/失效对象保护 |
| `Tests/Integration/ValidateDeliveryApplication.gd` | 分别明确两种地图后端，适配七类召唤池并复跑回归 |

已批准的事件日历为实际地图移动2400单位推进1日，购买引擎后4日触发幽灵。与main时间服务整合时须保留此已批准口径，不能仅因为出现另一个时间实现就改变事件节奏。

## 交付包与验证

交付包按本分支源码提交生成，包含全部新增/修改源码及依赖资源、SHA-256清单、测试日志与显示截图；不包含个人存档、getlogs日志包、.godot缓存或原始2.4GB交接ZIP。

包是针对修改起点的增量覆盖，不能直接覆盖最新main的上述重叠文件。已有完整仓库可切到本PR分支体验；需要合入main时，先完成上述接口合并并重新验证。

验证结果与运行说明见`二十事件整合与验收说明_2026-10-19.md`及交付包manifest。源码验证仅覆盖本分支；合并到main后的结果尚未验证。
