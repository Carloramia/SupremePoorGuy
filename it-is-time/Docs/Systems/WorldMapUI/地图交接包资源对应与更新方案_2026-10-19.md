> 下文保留首次资源迁入时的核对与规划。随后已完成运行时接入，新游戏默认新版、旧档保持原版；最终状态见 [实际接入记录](新版六边形地图接入_2026-10-19.md)。

## 本次完成范围

已检查 `地图编辑器系统合并完整交接包_20261019`，并将地图数据及全部素材依赖迁入 [FrontierEditor_20261019](../../../Content/Maps/FrontierEditor_20261019/README.md)。正式游戏继续读取 `FrontierDelivery_20261015`。本次是资源迁移和更新关系确认，不是新版六边形地图系统的完整切换。

原包 10,320 个文件全部通过 SHA256 校验。源数据共 10,877 格、631 个点位、9 条道路、3 处桥梁、39 处营地、41 张战场、27 处可破坏石头、20 条事件及 3 条辅助记录。

迁入 2,224 个美术/裁切资源文件，约 338.63 MiB；加上资料、源数据和 43 份改写路径后的 JSON，总目录约 419 MiB。包括 48 张高清底图分块和对应裁切、85% 树木资源及 511 个树木/灌丛/蛛网装饰点；未改变交付的摆放和尺寸。全部 2,642 条资源 URI 均能解析到本项目文件。

原包自身结构验证通过，但附带自动测试为 7/10，另有 111 项待配业务/效果警告和 11 个历史事件模块缺件。它们完整保存在 `Documentation`，不能将“素材已完整迁入”解释为“事件/真实战斗全部可执行”。

## 阵容与尚未绑定内容

39 处营地中，12 个阵容 ID 在现有 `EnemyRosters` 有同名文件，27 个没有。即使同名也不能直接复用数量，例如 `bandit_clear_team` 当前为 2 个人形，新数据为 4 个。新版敌军数量以战场 enemy 对象的 count 求和为准，不能继续照搬旧预设或根据图标猜测。

本次实际解析的 `CreatureFactory.DEFINITIONS` 为 human、stump_beast、wolf、snake、horned_beast、spider。交付仍未绑定的物种为 dog、rat、gong_beast、mineral_bird、sheep、dragonfang_archer。已有 Rat/Bird 角色场景不等于正式 Factory 已注册对应“巨鼠/食矿鸟”；体型、密度、攻击与剧情身份仍需确认，不能自动替换成灰狼、角兽等其他生物。

逐营地的完整敌军对象、数量与缺项保存在 [enemy_bindings.json](../../../Content/Maps/FrontierEditor_20261019/Migration/enemy_bindings.json)。本次保留所有 `definition_id=null`。现有巨鼠战斗禁用设置、召唤池与生物预设保持原状。

## 建议实施顺序

1. **只读显示与版本入口。** 在 MapCatalog 外增加显式的地图版本/格式选择，用新的适配器读取 hex 数据；逐场 ID 注册新生成的环境场景。完成预览验收后再切换默认版本。不要用 `ImportDeliveryMaps.py` 直接导入本包，它只接受旧的转换工程；旧 `import_level.gd` 要求 `frontier-map-editor`，本包导出格式为 `frontier-battle-level`。

2. **大地图渲染。** 使用 48 个原始高清块及 `pixel_size/rect/core/offset/clip_asset`，实现 even-odd 裁切与接缝处理，总览仅用于远景。保留图标的底部 anchor、图层、组合图标、85% 树木效果和装饰点击穿透。不能只铺 overview，也不能根据透明像素判断可通行。

3. **通行和迷雾。** 按平顶六边形 q/r 建图、六邻居寻路；桥梁是过河通道，wall/river/outside/未破坏石障分别约束，视野需保留遮挡。不要直接扩大当前步长 18 的矩形 AStarGrid 到新世界：全图约需 1,408,950 个矩形节点，而源图只有 10,877 个六边形格。共享石障必须等所有 owner 破坏才开放，破坏耗时按正式旅行速度计算三格，而不是把编辑器试玩的 1.8 秒写死。

4. **战斗环境与阵容。** 消费逐场编译的多边形对象，保留外围模糊/渐隐、空气墙、独立视觉/碰撞、环境区域效果；将 13 张旧候选和 28 张新增都转换成新的运行时 JSON 与 3D 包装。优先复用现有 BattleHost、部署、结果回执与 NPC，不覆盖角色脚本。继续维持“友军左、敌军右、靠近中段、只能左右朝向、通过 Z 移动对齐目标”，不要直接套用编辑器部署的任意朝向。装饰物保持目前禁用物理碰撞的策略，明确的障碍/危险区域分别适配。缺少物种的战场阻止进入并提示原因。

5. **存档显式迁移。** 当前世界范围为 `[4980,2970]`、出生点 `[700,2368]`；新范围为 `[27900,16350]`、出生点 `[3220,11372]`。格子与点位经过重新布置，不存在已验证的统一缩放换算。建议新游戏使用新版；旧档继续绑定旧版，之后提供显式转换（保留仓库、队伍、任务与时间，单独处理位置、探索、破坏、清剿和 pending battle）。不能把旧坐标与已清剿 ID 原样装进新版，也不能直接清空旧进度。

6. **事件后接入。** 20 条事件和 3 条辅助记录保留为内容配置，沿用 GameSession 时间与事务所有权。逐项补执行图、条件、奖励、战后/观战分支和回执；未配参数保持阻断，普通地点不能因为有正文就直接发奖。继续沿用现有空队伍先编队、战斗返回来源点和首次新游戏待办事项逻辑。

7. **切换与导出。** 全部验收通过后切换地图目录入口，并从 `export_presets.cfg` 移除本暂存目录的排除项；只保留最终使用的数据/美术参与导出，Source/文档/审计记录继续排除。旧版资源在旧档仍依赖它时不能删除。
