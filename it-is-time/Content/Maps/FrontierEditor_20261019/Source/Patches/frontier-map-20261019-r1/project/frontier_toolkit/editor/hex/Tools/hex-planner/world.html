山体编辑

按图片透明边缘生成，保留凹口和石间空隙；移动、缩放、旋转自动同步。删除以整组素材为单位；Ctrl+Z 撤销，Ctrl+S 保存。

素材置换

触发范围独立。山体吸附实边后，碰撞与遮视野会跟随图像尺寸、旋转和位置；更换素材后需重新吸附。未绑定美术的独立阻挡仍按蜂窝编辑。

石障交互

选择该石障后启动“试玩交互”，可移到所选点位旁验证破坏。每块独立保存ID与占用格。
