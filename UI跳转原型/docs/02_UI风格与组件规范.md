# UI 风格与组件规范

版本 0.7.8 · 2026-10-13 · 原生 Godot UI 原型

## 设计依据

保留手绘布局、独立活页纸、铜环装订和纸雕怪物。参考[《炼金模拟器》官方页面](https://store.steampowered.com/app/1210320/Potion_Craft/)的纸张、手作工具和场景化操作表达，以及[《多少兄弟》官方页面](https://store.steampowered.com/app/3934270/)的队伍管理和属性信息需求。参考用于信息组织与视觉方向，未复制其美术素材。

正文使用平整浅纸底与深墨文字。体积感集中在纸边、铜环和插图；确认召唤等主要操作保留赭黄，普通编辑与列表采用浅纸片。主题保留选中、禁用、悬停及键盘焦点状态。

## 信息与页面职责

- A1 常驻显示地区和地点、天数、魔力、下一事件与设置；地图下方保留一行情境提示。
- C1 展示环境、召唤倾向、消耗和已刻入符文；C2 放标题、法阵、固定绘阵工具及确认召唤；C3 放可折叠符文与奇物参考。
- D1 放标题、选中怪物插图、属性、改名和特性，出战／回仓库、回收固定在底部；D2 放怪物列表，筛选书签悬在右侧纸边。
- 点击符文行查看说明，怪物卡悬停速览信息；完整解释使用说明窗，避免常驻长段文字。

## 窗口与字体

原生窗口尺寸配合容器重新排布，关闭整画面等比缩放，避免小窗口把汉字一起缩小。最低支持1120×680；设置提供1120×680、1280×720、1440×810、1600×900、1920×1080。支持手动拉伸，预设受屏幕可用区域约束。更小窗口暂不支持。

以下是本项目设计值，不宣称是所有产品的统一标准：

| 内容 | 字号／约束 |
|---|---|
| 书页标题、怪物名称 | 24 px |
| 正文、数值 | 18 px |
| 符文简述、紧凑工具、提示 | 16 px，不随窗口缩小 |
| 常规按钮 | 最小高度42 px |
| 紧凑组内间距 | 6–8 px |
| 装订留白 | 装订侧36 px，外侧16 px |
| 纸页间隔 | 40 px |

全局使用随工程打包的小赖手写字体v3.126（OFL-1.1），主题统一引用，字体来源与许可见Assets/UI/Fonts。超长名称在列表裁切，详情与悬停保留完整信息；反馈限定一行，完整内容可悬停查看，避免推挤法阵。

## 滚动规则

优先整理信息层级，不用缩字消除滚动。1280×720默认七枚符文可一次扫读；C2绘阵操作和确认按钮固定，不随C1/C3滚动。D1常见怪物详情无需滚动，底部操作独立固定。

较小窗口、长刻入列表、扩展符文与奇物、长怪物详情及大量仓库怪物保留各自纵向滚动。滚动只影响所属内容，不移动法阵、纸内标题或固定操作；不引入横向滚动。

## 纸页与动效

C1/C2/C3为三张纸，D1/D2为两张纸。标题在纸内；铜环穿入空白装订边，正文避开孔位。筛选书签位于D2纸外、轻微压住纸边，文字不压住怪物条目。仓库／出战使用128×48页签，名称与数量分开；形态使用短标签，预留前后两排错落结构和后续icon入口。选中向外伸出12像素，正常／悬停／按下保持同一纸色，以位置表示条件启用。清空筛选会取消位置与全部形态条件，标签一起缩回。上下保留呼吸空间。

书签打开页面时纸页从左向右进入、地图整体右移，A1固定。关闭书页沿原路向左退出并淡出，地图在下方恢复，不继续向右移。战斗先结算，确认后大地图下拉遮住小地图，完成后才切换底层状态。简化动效开关保留。

## A2状态与增减动效（0.7.3）

左侧书签统一使用BookmarkButton主题变体，正常、悬停、按下、禁用保持相同轮廓、尺寸与纸色；键盘焦点框保留。跳转时底层操作仍会禁用，但不再切换到普通赭黄按钮的皮肤。离场地图使用当前渲染画面的冻结图像右移，不重新实例化布局容器，防止首帧状态丢失和重新排版。

新增动态A2按钮使用BookmarkSlot.gd固定槽位。出现时从左向右移入，消失时向左移出，退出完成才释放槽位；可以轻微错开顺序，纸片与文字始终不缩放。重复路由与快速反向切换会取消旧Tween并从当前位置转向；简化动效时即时设置最终状态。新增动态书签需沿用PartySlot／ReturnMapSlot结构。

ValidateA2Motion.gd实际渲染40项检查覆盖五枚书签的四种状态皮肤、出入方向、固定尺寸、已有按钮稳定、快速切换、C/D冻结画面逐像素一致和简化动效。


## 0.7.11 滚动条统一与布局稳定

PaperReliefTheme.tres统一设置VScrollBar/HScrollBar的scroll、scroll_focus、grabber、grabber_highlight、grabber_pressed：浅纸色轨道、铜色滑块、悬停亮铜、拖动深铜；轨道宽10像素，滑块最小长度32像素，三种滑块状态保持同一尺寸。横向同规格旋转，继续使用Godot原生ScrollBar的鼠标、滚轮和Range行为，不另做输入遮罩。

当前场景中的ScrollContainer使用SCROLL_MODE_RESERVE（场景枚举4），需要时显示滑块，短内容仅预留边槽；禁用的方向保持禁用。外层弹窗对固定内容仍禁用滚动，普通长说明使用RESERVE。轨道与正文之间保留6像素距离，避免贴字。

召唤C3同时测量符文、奇物各自的最小内容宽度，取最大值加预留边槽作为共同宽度下限。只预留滚动条不足以消除内容本身最小尺寸不同导致的跳动；此处不能改回“按当前可见页测宽”。切换时三张纸页、阵面、召唤按钮的Rect均保持一致。C1也预留滚动条空间，新增刻入内容导致溢出时不挤动中页。

验证：ValidateScrollPresentation 36项、ValidateSummonV2 697项、ValidateRitualPresentation 792项、ValidateEventPanel 26项、ValidateTasks 31项、ValidateFilterTabs 40项，共1622项，0失败。三档窗口反复切换大小列表、事件/待办由短变长、滑块原生滚动和最后一枚符文可达已验证。截图scroll_runes_stable.png、scroll_relic_stable.png、scroll_event_copper.png位于Tests/screenshots。

## 0.7.12 嵌套说明背景修复

嵌套说明打开前，在内存中冻结当前页面的显示区域，通过GameDemo/ModalBackdrop展示在遮罩下；它只提供背景，不接受输入、不复制按钮/信号、不写图片文件。弹窗栈每层保留自己的backdrop，关闭时恢复原页面，离开弹窗栈则释放背景贴图。这样既保留当前书页语境，又避免共享ModalHost重建内容后留下空黑底。

_has_page_root统一判断召唤/仓库/结果根页面，_show与_render_modal共同使用；战斗场景刷新不能重新显示其下方提示，避免主内容隐藏时footer被VBox挤到左上。回到实际地图或战斗时恢复正常底部提示。字体大小未缩小，也没有删掉正常提示功能。

ValidateNestedModal真实渲染34项，0失败；覆盖结果→特性→术语逐层返回、仓库/符文说明、正常战斗恢复、结果数据不变。召唤697、阵面792、事件26、待办31、滚动布局36及A2动效40项相关检查通过。截图nested_trait_context.png、nested_warehouse_context.png、nested_rune_context.png。
