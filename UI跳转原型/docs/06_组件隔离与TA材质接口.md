# 组件隔离与 TA 材质接口

**交接约束（2026-10-15）：改功能，不改已确认布局。需要改布局或存在布局风险时，先提交具体方案、影响与回退方式，经用户二次确认后实施；不得先改后确认。** 完整执行规则见[交接总览](../交接文档.md)。


版本0.7.4 · 2026-10-13。当前视觉表现保留；只优化事件窗容量，并增加组件边界和后续材质接入口。本接口不代表S1/S2/S3最终Shader已经完成。

## 需求依据

以[UI Shader材质需求案](../../References参考资料、怪物设计/美术参考图片/Shader效果对照/UI_Shader材质需求案_2026-10-13.md)为准：S1手绘线框、S2整体白底衬边、S3纸纹与局部毛边。新材质不处理文字和数值，不改变输入区域，不使用每帧随机或全屏滤镜；最终视觉取消浅投影。当前占位美术未直接改成新风格。

## 职责与信号

| 组件 | 只负责 | 对外接口 |
|---|---|---|
| NavigationPanel.gd | A2按钮绑定和上下文展示 | action_requested(action)，present_context(in_battle, animate) |
| BookmarkSlot.gd | 预留槽位、平移、淡入淡出 | set_present(present, animate, delay) |
| WarehouseView.gd | 页签、数量、筛选状态展示 | back_requested，position_filter_requested，form_filter_requested，clear_filters_requested；present_filters(position_id, forms, counts, animate) |
| MonsterNote.tscn / .gd | 条目文字、选中、提示 | present(id,title,form,position_label,hint)，set_selected；selection_requested(id) |
| FilterTab.gd | 突出／收回，原生Button功能 | set_active(active, animate)，继承pressed/toggled/icon |
| UISkinSlots.gd | 视觉资源替换、独立实例参数、恢复 | shared_preset、local_preset、enabled、refresh() |
| GameDemo.gd | 接收动作请求、路由、调用模型、向视图提供数据 | 不由视觉脚本反向引用 |
| PrototypeState.gd / RuneRules.gd | 存档、事务、业务规则、召唤识别 | 视觉组件不得引用 |

按钮仍是原生Button，保留禁用、焦点、键鼠事件和点击区域。装饰层MOUSE_FILTER_IGNORE，不能遮挡按钮输入；D2纸面延伸的输入遮挡仍单独保留。动画回调只结束视觉状态，不扣费、不生成、不保存。当前控制器仍是原型宿主，不宣称业务层已拆成独立插件。

## TA 从哪里开始

1. 在Godot打开 `Scenes/UI/TASkinPreview.tscn`，F6运行独立预览，无业务控制器和存档。
2. 复制 `Assets/UI/PaperRelief/DefaultSkin.tres` 为自己的测试资源，不先修改公共默认值。该Resource的脚本为 `Scripts/UI/UISkinPreset.gd`。
3. 将测试资源指定给预览场景根节点的 `Preview Preset`，点击“应用测试预设”；“恢复当前外观”撤回。可测试窄按钮、宽按钮、纸页、书本、头像及文字数值。
4. 按需求案另交原始／S1／S2／S3／组合对照、轻中强预设及最终Shader。这个预览是接口沙箱，不替代TA的完整视觉与性能验收场景。
5. 负责人验收后，再指定公共DefaultSkin，或仅给某组件VisualSkin的Local Preset赋值。清空Local Preset回到公共资源；Enabled=false恢复接入前资源。

## 预设字段

| 字段 | 用途与约束 |
|---|---|
| surface_texture / surface_region | 底纸；Region默认为整张新纹理，支持图集区域。页纸原裁切在撤回时恢复 |
| surface_material | S3纸纹／局部毛边材质，仅落在底纸层 |
| outline_texture / outline_material | S1透明中心的线框素材与材质；九宫格，不烘焙文字 |
| patch_margin | 生成底纸和线框的九宫格保护宽度；与交付素材匹配 |
| cutout_material | S2完整主体白底，用在插画／图标TextureRect上，不落在Caption上 |
| decoration_material | 铜钉、夹子等装饰的材质 |
| stable_seed | 实例固定种子，悬停／按下不重抽 |
| remove_legacy_shadows | 接入新底纸／线框后移除旧Flat纸页投影；默认true，未接新资源时不改变当前画面 |

Local Preset为整套局部替换，不与公共预设逐字段混合。复制公共预设再修改局部字段，避免无意清空其他效果。素材或参数修改会发出changed并刷新；资源切换或窗口尺寸改变也会刷新。每个目标复制材质实例，绝不直接修改共享ShaderMaterial的实例参数。

可选Shader uniform：`ui_size_px`（vec2，目标显示尺寸）、`ui_seed`（int，稳定种子）。仅当Shader声明同名uniform时传入；其他强度、保护区、纹理采样与S1/S2/S3开关由TA材质自身提供，不约束算法。不要在Shader中用TIME或每帧随机制造静止纹理游动。

## 已接入的视觉槽位

- ActionButton：VisualSkin/Surface和Outline为独立NinePatch。指定新底纸时，将原按钮各状态底图替换为空StyleBox但复制原内容边距，文字仍由Button绘制。撤回时恢复原样式；未启用时不覆盖编辑器的局部样式。旧按钮底图自带轮廓时，TA应配套替换surface和outline，避免双重边框。
- LooseLeafPage：Paper负责底纸，VisualSkin/Outline负责新线框；新线框接入后隐藏旧Flat轮廓，保留原布局留白、尺寸和D2右伸范围。撤回时恢复原StyleBox。
- BoardSurface：Paper为底纸；新Outline接入时隐藏WoodFrame，撤回恢复；Clip、LeftRivet、RightRivet为独立装饰目标。它覆盖事件和通用弹窗的视觉底板。
- MonsterPortrait：Artwork与ReferenceArt分别接S2。正文、标题、概念图提示不套材质。
- SummonBookButton：Icon接S2，Caption仍是独立Label。
- 其他线性组件、分割线、地图装饰、法阵：保留原节点、输入和绘制脚本。可实例化同一UISkinSlots，配置surface_target／illustration_targets／decoration_targets／legacy_outline_targets，或单独提供视觉层。不能给整个页面或RuneBoard根节点套会改变文字、位置或连通性的滤镜。此接口不声称已经实现全部线条的最终S1视觉。

白底需要原图带透明留边；Shader不能自行突破控件或父级裁切范围。新增留边应在视觉素材画布中规划，不改变按钮点击矩形。纸纹需说明通道、平铺、sRGB／线性用途；轮廓素材透明中心，长短九宫格都检查接缝。取消投影也需检查TA贴图本身是否烘焙了阴影。

## 事件窗

EventPanel.tscn独立承担正文滚动和固定选项。事件使用明确的modal kind=event，约80%窗口宽度、上下保留边距；正文20px，行距8px。长文只滚动DescriptionScroll；Commands固定在外部，至少支持4项测试选项可达。标题、返回和反馈独立。奖励与重复领取限制仍由原模型处理，未改事件内容与奖励值。

## 验证与交付边界

ValidateComponentContracts.gd验证组件在没有GameDemo的场景中发信号、显示数据、替换／撤回资源，且按钮尺寸与文字不变。ValidateIsolation.ps1禁止Scripts/UI引用模型、控制器、磁盘IO和业务写入。ValidateEventPanel.gd覆盖1120×680、1280×720、1920×1080、长正文、4选项、一次性奖励和返回。

TA交回后仍需完成需求案中的全部视觉、不同背景、状态和目标设备性能验收。本轮不交付最终Shader，不默认应用尚未验收的材质，也未向TA发送消息。

## 战斗地点预览接口（0.7.5）

LocationHint.tscn为独立小纸卡，继承纸页材质槽位；所有子内容忽略鼠标，不含按钮、不含业务数据写入。WorldView负责悬停生命周期和边界定位。外部可调用set_location_previews({"desert":{"tags":"【沙漠】【沙】","types":"兽形 / 蛇形","abundance":"少量"}})填入侦察概况；示例只演示字段，不是默认真实数据。未知字段显示待侦察。点击标记仍通过location_clicked交给宿主决定进入场景。

事件可用性（0.7.6）：宿主根据EVENTS.has_followup与模型completed生成已结束的一次性事件ID，调用WorldView.set_unavailable_events(ids)。展示层只隐藏指定标记，不读存档、不计算奖励。当前traveler没有后续；完成后隐藏，重新读取进度仍隐藏。离开事件不写完成；保存失败不移除。

待办展示（0.7.8）：TasksView.present_tasks(tasks:Array)接收title/description/done/action快照，发action_requested(action)。宿主处理前往和进度；视图不写完成、不发奖励。TasksPanel及TaskRow独立布局，字体由公共主题提供。所有运行界面统一使用Fonts/Xiaolai-Regular.ttf，替换字体不需修改TA材质或按钮输入。
