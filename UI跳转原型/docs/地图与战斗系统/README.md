# 地图与战斗接入入口

2026-10-13 · UI原型0.7.6。

主协议：[系统接入适配与联调协议](../07_系统接入适配与联调协议.md)第3、6、9、10节。

目前WorldView只是占位展示。已有点击通知、悬停预览数据和隐藏事件ID入口；没有真实移动、抵达判定或战斗结束回执。scene_requested只是通知，GameDemo仍执行自己的路由，接入时必须替换对应分支，避免双切景。

地图负责人交付：正式地点ID映射、抵达／可进入判定、A1上下文快照、地点预览和事件可用性快照。战斗负责人交付：按monster_id部署、唯一battle_id、加载失败、结束／退出回执、结算数据与奖励提交结果。协议中的建议字段不是已实现API。

保留：A2增减动效、C/D进入右移及关闭左退、结算确认后大地图下拉。不要把发奖放进Tween回调。玩家界面没有“跳过战斗”；_skip_battle仅测试调用。

最低回归：连点不双切；满队／空队按正式规则处理；胜负／退出／加载失败能恢复；相同回执不重复发奖；结算先于下拉；完成事件不会在幕布副本复活。
