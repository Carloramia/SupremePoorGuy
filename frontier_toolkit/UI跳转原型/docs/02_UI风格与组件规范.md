# UI 风格与组件规范

版本 0.5 · 2026-10-11 · 当前纸雕 UI 示意，待团队确认 · 对应 `Assets/UI/PaperRelief/PaperReliefTheme.tres` 与 `Scenes/UI`

## 基础信息

适用原生 Godot 原型，不替换正式游戏工程。`UI_MAIN_WORLD` 是大地图 HUD；`UI_POPUP_RITUAL` 是书本入口打开的召唤画板；`UI_POPUP_WAREHOUSE` 是独立仓库；`UI_POPUP_RESULTS` 是召唤后安置页；`UI_POPUP_MONSTER_DETAIL` 是详情页。召唤和仓库共享视觉组件，不共享职责文档。布局仍是三栏召唤、横排仓库卡和三张竖版结果卡。

当前实机示意：[召唤](../Tests/screenshots/03_engraved.png)、[结果](../Tests/screenshots/05_results.png)、[仓库](../Tests/screenshots/10_warehouse.png)、[运行演示](../Tests/previews/PaperRelief_v1.mp4)。素材依据与交付表见 [纸雕美术指导](美术方案/03_纸雕UI_美术指导与素材格式.md)。

## 设计目标

以用户提供的纸雕怪物素材统一界面：用骨白底纸、炭黑轮廓、赭黄操作片和少量锈铜装饰，体现层叠剪纸与浅纸剧场。正文保持平整清楚，体积感集中在边缘和图像。保留已有卡片、说明窗及画板进出逻辑，不复制参考游戏的红黄界面，不让纸纹、阴影和装饰遮挡数值或操作。

## 唯一视觉参数入口

| 参数 | 当前值 | 用途 |
|---|---|---|
| INK | #27231F | 主要文字、轮廓和全局背景 |
| PAPER | #F0E3CE | 窗口、卡片和正文底色 |
| OCHRE | #BD7D32 | 普通操作纸片、选中提示和薄叠层 |
| COPPER | #94513F | 铜钉、结构边、次要强调 |
| ALERT | #A45243 | 危险语义，必须搭配文字／图标 |
| MUTED | #60634B | 次要环境标识，不作全局按钮底色 |

字体：优先 Microsoft YaHei，回退 Noto Sans CJK SC / sans-serif。正文18，说明16，卡片标题24，窗口标题26–28。常规按钮最小高度42像素；间距12，外边距16，弹窗外侧22–26。所有公共按钮的悬停、按下、禁用和键盘焦点共用可直接在 Godot 编辑的 `PaperReliefTheme.tres`，不再由控制器临时生成主题。

当前主题使用独立底纸与空白叠层按钮 PNG，主操作用炭黑 PrimaryButton 主题变体。叠层框、夹子、铜钉在 BoardSurface 分别装配。正文、数值、符文和命中区不烘焙。`UIStyle.gd` 仅服务临时绘制，不是控件样式的第二来源。此前青绿水粉 A 测试保留在 SketchbookA，当前运行不再引用其主题。

美术方向为本轮示意，不把选色与纹理参数视为最终批准。地图、喷涌和正式角色动画仍是占位。怪物插图使用用户原图，不代表召唤系统已能生成同样外观。

## 公共组件与层级

- WorldView：连续背景与地点标记，不画六边形格线，不承担地图移动。
- RuneBoard：61格输入面；符文书小图只画局部形状，不缩成难以辨认的61格盘面。
- MonsterPortrait：本轮按人形／兽形／蛇形展示用户原图，附“概念图 · 非生成结果”；它们是带场景的插图，不是透明战斗角色。显式 Artwork 贴图优先；关闭 Use Reference Examples 可回到矢量占位。后续正式实例使用资产 ID，不按名字或形态强行对应唯一外观。
- 怪物卡：形象 → 名字与状态 → 属性 → 特性 → 详情／分配操作。
- 详情：只展示这一只实例的数据，可改名；特性继续打开说明，关闭说明回详情。
- 弹窗：统一底纸、炭黑赭黄叠层框、顶栏返回；最上层可交互，下面仅作上下文。

## 交互规范

必须/MUST：当悬停可操作元素，则展示文字说明或明显悬停；禁用不能只换颜色，应提供原因。

必须/MUST：当打开说明窗，则不继续事件、不移动队伍、不重新生成产出；关闭回来源。

必须/MUST：当结果关闭，则未安置怪物入库，不能消失。

必须/MUST：当清空法阵，则先确认；取消不改变当前布局。改名在点击保存前不落盘。

应该/SHOULD：复杂特性数量增长时使用滚动与摘要，不无限压缩字号。640宽手机布局不作为本轮目标。

## 场景化与适配约束

基础信息：`UI_MAIN_WORLD` 为主界面，`UI_POPUP_RITUAL` 为召唤窗口；入口为地图书本，父界面为大地图。返回关闭最上层窗口，不切换到网页。

- 必须/MUST：当点击地图右下角书本，则打开召唤法典，且遮罩禁用底层操作。
- 必须/MUST：当刻入列表变长，则只增加左侧滚动内容，且中间阵面保持正方形与原位置。
- 必须/MUST：当窗口尺寸改变，则整体等比缩放1280×720设计画布；非16:9留边，禁止非等比拉伸。
- 必须/MUST：当调整组件资源，则同类实例使用共同变化；程序不得在刷新数据时重新指定组件尺寸、边距或贴图。

召唤组件：`RitualPanel.tscn` 定义 Columns、LeftScroll、BoardFrame、RightScroll、Summary、Controls。左右默认最小宽210／260；BoardFrame 使用 AspectRatioContainer（比例1，Fit）；Summary预留56高，Feedback预留50高。正文最多两行，避免内容引发布局跳变。修改字号后应同步预留文字高度并运行布局回归。

整体缩放是统一适配策略；不通过反复改变各节点的 `scale` 适配。独立调试窗口无需改业务代码。具体编辑路径、贴图插槽与组件工作台见 `04_UI组件可视化调整指南.md`。

## 画板动效与分件

打开一级系统画板：0.30秒滑入；手动关闭：0.22秒向右移开；嵌套说明与列表刷新不重播。只移动BoardMotion/MotionRoot，不修改Scale或容器尺寸；动画中拦截输入，结束恢复焦点。GameDemo的Animate Panels可关闭视觉动效，目前不是玩家设置菜单。

底纸／叠层框／空白按钮分别为 PNG；书本／夹子／铜钉为独立 SVG；属性 StatButton 为紧凑纸签。组件沿用 WoodFrame 节点名以保持接手路径稳定，但纹理已经是纸雕叠层框，不再是木纹。当前资源与切片见 [PaperRelief 素材入口](../Assets/UI/PaperRelief/README.md)。

## 美术指导与交付格式

正面平视、浅层构图，强调剪切形状和有限纸层。体积靠两三层错位纸边，不靠写实高光、厚木框或大面积投影。温暖背光可用于插图和场景装饰，正文区不能因此泛光或降低对比。铜钉在 UI 中只是装饰，不暗示可操作连接点。不要叠加毛刷轮廓、裂纹、仿古污渍或伪文字来制造手作感。

- 必须/MUST：当交付可替换分件，则/THEN 使用 PNG RGBA、sRGB、真实透明背景，且/AND 不烘焙文字、棋盘格、点击区或其它部件。简单图标可交 SVG。
- 必须/MUST：当更换按钮状态素材，则/THEN 保持画布、对齐与九宫格一致，且/AND 悬停／按下不能导致布局跳动；当前四态复用同一纹理，仅调色。
- 必须/MUST：当交付正式美术，则/THEN 同时提供分层源文件、分件导出和清单，且/AND 标注尺寸、切片、透明边距与版本。本轮生成 PNG 不是 PSD／KRA 分层源文件。
- 必须/MUST：当编辑组件视觉，则/THEN 只编辑对应场景、主题或资源，且/AND 不在 GameDemo 内写尺寸与贴图替换逻辑。
- 应该/SHOULD：当准备生产贴图，则/THEN 按显示尺寸约 2 倍绘制后验收，且/AND 在实际 1280×720 画布检查，不能只看原图缩略图。

具体资源尺寸、命名、母版与导入像素的区别、透明通道验收和替换步骤统一维护在 [纸雕美术指导与素材格式](美术方案/03_纸雕UI_美术指导与素材格式.md)，避免两份规格表互相矛盾。

## 导航与数据边界

大地图书本 → 召唤法典 → 确认扣费与保存 → 当地喷涌 → 安置；大地图管理入口 → 仓库 → 详情 → 属性／词条说明。返回只关闭最上层，结果关闭时剩余入库。原图插槽只影响显示，不参与生成、物理、扣费或存档。

数据来源为共享 PrototypeState 与独立 RuneRules；打开页面和操作成功后刷新现有实例。UI 不另建库存缓存，不在打开卡片时随机生成数值或外观。正式接入边界见团队接入速读，现有通知信号不是可中断的宿主 API。
