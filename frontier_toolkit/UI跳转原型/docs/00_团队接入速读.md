# 给接管成员：从哪里开始，怎样接入

2026-10-11 · 原生原型0.5 · 先独立验证，再接入正式项目。

## 可直接转发的话

这套内容在 `SupremePoorGuy/UI跳转原型`。请先读根目录README，再按你负责的召唤／仓库打开各自的接管导引。用Godot 4.7.2导入这里的project.godot，F5独立跑通；只调UI可打开Scenes/UI/UIWorkshop.tscn后F6，不写进度。不要把整个原型覆盖进正式工程。

接入时保留现有地图移动和战斗模块，逐项替换本原型的占位流程。GameDemo和PrototypeState仍是共享集成文件，需要集成人员统一协调，不能两边各复制一套库存或存档。UI场景、主题、底纸、叠层框、夹子和按钮底均可单独调整；本轮纸雕方案是测试美术，不是最终资产。完成后交回修改清单、接口变化、测试结果及仍未接入的部分。

## 正式工程的接入顺序

1. **先跑独立版。** 核对大地图书本打开召唤、法阵输入、喷涌、结果安置、仓库改名、出战、跳过测试战斗与返回。与当前原型区分，不先修改正式启动场景。
2. **开集成分支，核对路径。** 所有运行资源都在Scenes／Scripts／Assets；引用当前使用res://Scenes等通用根路径。若正式工程有同名目录，不得直接覆盖。建议放在例如res://Modules/UIPrototype/下，再统一改这批资源内部的res://引用。该前缀是接入建议，尚未自动迁移。
3. **接宿主，不搬占位地图。** 使用地图组已有移动、时间与地点系统。WorldView只作验证背景，不含真实寻路。现有信号是通知，不是“等待宿主接管”的可中断回调；仅连接信号不足以替换占位行为，还须由集成人员移除对应测试分支，避免宿主与原型同时切场景。
4. **接共享数据与存档，再接正式生成。** 先决定由谁持有魔力、怪物唯一ID、队列和待安置结果。当前PrototypeState自带持久化，不能与正式仓库各存一份同一实例。不要复制project.godot的custom_user_dir覆盖主工程；集成后须使用明确隔离的测试保存路径，或替换为正式存档适配。默认存档加载不能无审查带进主流程。
5. **逐个替换占位出口。** 事件交给事件模块；战斗交给真实场景和结束回执；正式生成服务接替测试生成。保持“成功写入产出 → 喷涌 → 展示同一批怪物”，演出不能重复扣费或再随机生成。
6. **最后接UI与美术。** 保留原生组件、唯一节点名、正方形法阵、独立滚动和文字节点。先换贴图，不在业务脚本重建整页。公共画板动画由公共BoardMotion负责；频繁列表刷新不重播进场。
7. **回归后再切入口。** 原型测试只能证明原型本身；正式宿主还要补测真实地图、真实战斗与正式存档。交接文档更新后再合并。

## 现有接口与必须补的适配

| 当前实际存在 | 当前含义 | 正式接入注意 |
|---|---|---|
| location_interaction_requested(location_id, kind) | 点击测试地点的通知 | 不代表移动已抵达；监听不自动阻止测试弹窗 |
| scene_requested(kind, location_id) | battle／summon演出通知 | 原型还会继续自己的_show分支；接入方须明确切景唯一负责人 |
| party_changed(monster_ids) | UI成功转移后的队列通知 | 直接调用State不自动通知；按monster_id部署，不用名称或列表位置 |
| RuneRules.export_layout / import_layout | version2的placed／placedRelics快照 | 不把UI纸纹或图案贴图当作规则输入 |
| PrototypeState.summon | 测试扣费、生成、保存pending的事务 | 正式生成不能在信号回调里再做一次扣费／生成 |
| move_monster / rename_monster / store_pending | 唯一实例转移、改名及剩余入库 | 正式仓库适配后仍需失败回退、上限和不复制实例 |

目前没有可直接跨工程调用的独立召唤服务／库存插件，也没有真实地点上下文注入、天气权重或完整战斗回执API；不要把建议接口名当成已实现功能。

## 接入完成的最低验收

- 大地图现有移动系统不受影响，书本可直接开召唤；事件不被强制送进战斗小地图。
- 相同monster_id在结果、仓库、队列间移动，不复制；满队失败不丢怪物。
- 扣费、产出、结算只执行一次；保存失败能回退；退出重启可恢复待安置结果。
- 真实战斗与召唤演出由确定的一方切景，不发生双切景或重复领奖。
- 换纸底／框／按钮贴图不改变交互命中；六种尺寸、滚动、长提示、嵌套返回正常。
- 提交修改文件清单、接口对照、测试证据、未完成项；共享文件的改动已协调。

本文件是接入指引，不声称正式主工程已经接入。独立原型的总交接文档仍是运行事实的入口。
