## 1. 总体目标与范围

请在原生 Godot UI 中统一实现手绘线框、剪纸白底衬边、纸面颗粒与局部毛边。文字和数值保持清楚，组件可视化编辑，素材可独立替换。本轮取消 UI 浅投影，不制作全屏模糊、持续抖动或发光白边。

### 设计目标

界面呈现为手绘在纸上的画板与剪纸剧场。线性元素具有真实笔触；独立图形由白色纸底从背景中分离；纸面颗粒与线框局部缺墨共同强调纸张质感。不同系统共享这套视觉规则，同时保留各自功能和交互边界。

| 需求 | 使用位置 | 依据 |
| --- | --- | --- |
| S1 手绘线框 | 全部线性 UI 元素 | 用户图 1—3 |
| S2 白底衬边 | 头像、引导物、图标、徽章 | 用户图 4—5 |
| S3 颗粒与毛边 | 纸面、色块、线框局部边缘 | 用户图 6 |

### 生产分工

基础素材提供纸纹、笔触、剪纸形状和装饰本体；Shader 与材质参数统一颗粒、局部毛边、白边宽度和颜色；AI 可生成书本、夹子、花饰、纹章等独立装饰；Godot 组件负责文字、数据、布局与交互。具体实现方案由 TA 决定。

固定图形可以使用独立图片。可伸缩的框线和按钮不应做成整张固定截图；Shader 也不承担凭空生成图 1—3 复笔结构的任务，基础笔触应由素材或可编辑线条提供。

### 适用范围

适用于大地图 HUD、召唤、仓库、结果页及详情窗；不修改地图移动、召唤生成规则、库存数据或怪物物理模拟。本案是视觉需求交付，不代表工程已完成接入。

视觉依据：本案明文要求与用户六张图优先。R1—R6 为校正后补充参考，只解释局部效果，不要求照搬主题、构图或整套画风。试验建议与已确认要求分开标注。

## 2. S1 手绘线框与笔触强化

状态：必须实现。以用户图 1—3 为主参考。

### 使用范围与目标

使用范围：所有线性 UI，包括面板框、按钮框、分割线、标签框、选中框、进度条外框、线性图标及召唤界面的线性装饰。文字和数值不套用笔触处理。

### 不采用

整圈机械加粗、霓虹描边、每帧随机抖动、所有线条同样破碎。小图标和密集线条应减少复笔，保留辨识度。

### 可调项目

线宽、粗细变化、轮廓颜色、复笔强度、断墨程度、轻微不规则程度及稳定随机种子。应能按组件调整，也能复用统一预设。

### 交互与验收

- 必须：当面板拉长、按钮改宽或图标缩小时，线条保持同一视觉尺度，不出现拉长的笔纹或接缝；且不改变原有布局与点击区域。召唤阵中承担输入的线段必须保持位置和连通关系准确，只修饰视觉边缘。
- 必须：悬停、按下、禁用和键盘焦点状态沿用统一笔触；鼠标焦点不能触发重新随机生成整套线条。

### 搜索关键词

手绘墨线边框 / 钢笔复笔线条 / hand drawn UI border / rough ink stroke / sketch outline shader

## 4. S2 剪纸白底衬边

状态：必须实现。以用户图 4—5 为主参考。浅投影取消。

### 使用范围与目标

使用范围：怪物头像、引导物、书本入口、地点图标、词条徽章等独立图形。大面积矩形面板不默认再包一圈厚白边。

目标：沿完整主体的外轮廓生成连续白色纸底，并留出可见的留白宽度，形成模切纸片感。内部黑色笔触仍属于图案；白底不是另一条黑色描边，也不是向某个方向偏移的投影。

### 取舍

### 交互与验收

必须：当替换透明图标或改变显示尺寸时，白底仍贴合完整主体、不被裁切、不糊成光晕；且不改变点击范围。成组装饰或完整怪物头像应按整体轮廓处理。白底只允许非常轻微的纸边变化，不得破碎成齿状亮边。

## 6. S3 纸面颗粒与线框局部毛边

状态：必须配套生效。以用户图 6 为主参考。

### 使用范围与目标

使用范围：面板底纸、按钮及卡片色块，并配合线框局部边缘。纸面细颗粒表现材质；边缘细碎缺墨、磨损和毛边表现颜料落在纸上的触感。两者是同一项组合要求，不拆成互不相关的滤镜。

目标：面内为低对比的细颗粒，边缘只在部分区域变粗糙。主轮廓仍清晰，毛边不能吞掉主体线条或使交互线段看似断开。图 6 的强烈剥落只作为强度上限，不默认照搬。

## 8. 素材与组件交付要求

生产方式：素材打底、Shader 统一、装饰独立拼装。

| 交付对象 | 负责内容 | 保留边界 |
| --- | --- | --- |
| 纸纹与笔触素材 | 基础纸面、灰度笔纹、局部磨损遮罩 | 可独立替换，不含文字 |
| Shader 与材质预设 | S1、S2、S3 的强度与开关 | 编辑器可调，不改业务 |
| AI 装饰分件 | 书本、夹子、铜钉、花饰、纹章 | 单件透明，不生成整页 UI |
| Godot 组件 | 尺寸、布局、文字、数据、输入状态 | 共享视觉，独立系统职责 |

### 资源格式与替换

- 必须：装饰图片交 PNG RGBA、sRGB、真实透明背景；简单固定图形可交 SVG。纸纹或遮罩注明使用通道、是否可平铺。按钮、底纸、边框、装饰分别交付；文字、数值、点击区域不烘焙进图片。
- 必须：优先保留不含白边的主体原图，由 S2 控制白底；若选用预制白底，应提供无白边版本，避免叠加双重白边。标注画布尺寸、对齐基准、显示尺寸、透明留边、九宫格区域和版本。
- 应该：AI 生成图先筛选统一笔触和配色，再检查透明边、细线、伪文字与结构错误。Shader 只统一表面表现，不负责修正 AI 画错的形状或补回缺失的结构。

### 组件与隔离

- 必须：提供公共预设和单组件调整入口；在 Godot 编辑器可视化查看和替换。召唤、仓库共用材质风格，不绑定各自数据或规则。底纸、边框、装饰、插画和文字应能分别控制。
- 必须：先在独立测试场景验证，记录接入步骤和资源索引，再由负责人接回项目。不得为了统一风格改写召唤规则、库存、地图移动或输入逻辑。不能用全屏滤镜同时处理文字与所有素材。

### 试验建议，非定稿数值

以 1280×720 设计画布测试关闭、轻、中、强预设。线宽、白边宽度、颗粒大小与毛边程度分别比较；不预先规定算法、采样次数或固定实现结构。

## 9. 验收与交接清单

### 同素材对照

请先用同一套素材出原始、仅 S1、仅 S2、仅 S3、组合效果五组对照，再统一选择轻、中、强中的默认强度。测试页至少包含长短分割线、圆角框、异形徽章、书本图标、一张怪物头像和带正文数值的按钮。

| 验收项 | 通过标准 |
| --- | --- |
| 风格覆盖 | 全部线性 UI 沿用同一笔触语言，不只处理头像或按钮 |
| 白底 | 整体外轮廓连续；无投影、无发光、无双重白边 |
| 颗粒与毛边 | 同时可见、分别可调、局部粗糙、主线仍清楚 |
