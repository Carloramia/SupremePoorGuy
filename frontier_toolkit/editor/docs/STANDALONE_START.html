Frontier Studio · 地编独立版

完整解压后即可离线编辑地图。无需安装 Godot 或 Node.js，推荐 Edge / Chrome。

打开地图编辑器 →

第一次使用

  1. Windows 可双击 启动编辑器.cmd；其他系统打开 editor/index.html。
  2. 左侧选择探索地图或营地战场；从素材与要素库选择类型，再点击画布摆放。
  3. 右侧修改位置、尺寸、视觉、碰撞、效果与关联 ID，点击“应用参数”。
  4. 中键或空格拖动画布，滚轮缩放；Ctrl+Z 撤销，Ctrl+Shift+Z 重做。
  5. 用“场景预览”或“迷雾模拟”检查布局；制作时回到“布局编辑”。
保存最重要：浏览器不自动保存。刷新、关闭或换电脑前，点击“保存工作集”，保留下载的 *.mapproject.json。下次点击“打开”载入自己的文件。

保存与交付

  1. 经常保存工作集。文件可能位于浏览器“下载”目录。
  2. 点击“检查配置”，点击错误定位对象并修复。
  3. 检查通过后“导出配置”，得到 *.level.json。
  4. 将工作集、导出配置和修改说明一起发送给开发成员。导入的图片会嵌入工作集。

操作提示

功能提示
道路参数面板支持中心线节点增删、调序和画布编辑。
营地绑定战场、部署区、敌方配置、战后事件及关联障碍。
六边形战场修改尺寸不会自动缩放物件；越界需处理。吸附步长可调至 0.5 或 1。
区域视觉、点击范围、碰撞、效果区和部署区分别配置，不根据图片自动推导。
迷雾区域揭示与地标发现独立。全揭示、破障和胜利模拟不写入源配置。

范围说明

独立包用于关卡制作、参数配置和预览。正式战斗、数值效果、真实 Godot 场景运行和转换由开发侧游戏工程执行。直接打开编辑器会载入示例，不会自动载入上次编辑的文件。
