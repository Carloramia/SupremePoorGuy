# Frontier Studio · 地编独立版使用说明

此压缩包只包含地图编辑器，不需要安装 Godot、Node.js 或 npm 依赖。推荐使用电脑上的 Edge 或 Chrome。

## 1. 解压与打开

1. 将 ZIP 完整解压到任意本地目录。
2. Windows 双击根目录 `启动编辑器.cmd`；也可右键 `editor/index.html`，选择 Edge / Chrome 打开。macOS / Linux 直接打开 HTML。
3. 初次启动显示“边境地图工作集”，包含探索地图和营地战场示例。
4. 不要只从压缩包中打开某个 HTML，不要移动或单独发送 `index.html`；它需要同目录代码和素材。

浏览器不会自动保存编辑结果。刷新或关闭前务必保存工作集。此包可离线使用。

## 2. 编辑地图

左侧选择地图和要素，中间画布摆放，右侧调整参数，下方对象列表与配置检查。

| 操作 | 用法 |
| --- | --- |
| 放置 | 点击左侧类型，再点击画布；或拖放类型卡片 |
| 选中 / 定位 | 点击画布对象；对象列表单击选择、双击居中 |
| 移动 | 拖动选中对象，或在右侧输入精确位置 |
| 参数 | 编辑后离开输入框或点击“应用参数”；视觉大小、碰撞和效果范围分别设置 |
| 复制 / 删除 | 右侧按钮，或 Ctrl+D / Delete |
| 平移 / 缩放 | 中键或空格拖动；滚轮缩放；“适配画布”查看全图 |
| 吸附 | 勾选吸附，按世界单位步长摆放；战场制作可将步长调至 0.5 或 1 |
| 历史 | Ctrl+Z 撤销；Ctrl+Shift+Z 重做；输入框内先使用文本编辑行为 |
| 独立查看 | 左侧开关视觉、道路、碰撞、效果区、部署区、迷雾等辅助层 |

需要空地图时，点击“新建”→“建立空工作集”；恢复示例用“新建”→“载入示例工作集”。左上“＋”新增探索地图或独立战场。

探索地图保持连续 2D，不显示整套 Hex 格线。道路在右侧编辑局部中心线节点、宽度和样式；“画布编辑”拖动节点，“画布加点”追加，Esc 结束。衬布为独立底层；装饰不自动产生碰撞。

城镇、小屋、营地设置唯一 ID、视觉、点击范围和事件。营地绑定战场、部署区、敌方配置和战后事件；路障的被阻挡 ID 只填写需要限制的地标或连接。跨越障碍必须设置条件和落点。条件/事件等 ID 由开发或策划提供，在“条件 / 事件引用表”维护。

战场为可调六边形，改变半径或朝向时保留物件坐标，越界会报错。平面坐标是 X/Z，另有离地高度 Y。碰撞障碍、坑洞、荆棘、泥潭和蛛网分别配置体积或效果区；己方部署槽位需要在场内、区内，且不落入障碍或坑洞。敌方怪兽数量不限三只。

## 3. 预览与迷雾

“布局编辑”可修改配置；“场景预览”隐藏辅助线；“迷雾模拟”点击空地移动模拟玩家。地图设置可调整揭示半径、初始区域、颜色、透明度、羽化及探索保留模式。地标发现状态独立于区域揭示。

可临时全揭示、调整模拟怪兽数量、模拟外部条件和战斗胜利、重置预览。破障只解锁关联营地，点击解锁营地可预览焦点放大并切入对应战场。战场中心事件可预览召唤/升级选项。

这些都是检查配置用的临时状态，**不会保存进关卡初始配置**，也不会执行真实战斗、伤害、控制或奖励。正式运行与 Godot 转换由开发成员完成。目标场景的 `res://...` 是游戏项目引用，不要求把游戏工程放入此压缩包。

## 4. 保存、重开与交付

1. 经常点击“保存工作集”或 Ctrl+S，保留 `*.mapproject.json`。浏览器可能打开保存对话框，也可能下载到“下载”目录。
2. 重开时点击“打开”，选上次保存的 JSON。初次打开编辑器始终显示示例，需手动打开自己的文件。
3. 点击“检查配置”，点击错误定位对象。未完成时可以保存工作集，但有错误会阻止导出。
4. 检查通过后点击“导出配置”，生成 `*.level.json`。
5. 给开发成员发送工作集和导出配置，建议命名 `关卡名称_作者_日期_v01`；说明使用的业务 ID 及尚待处理的问题。

图片使用“导入图片素材”添加，单张不超过 8 MB。导入的图片会嵌入 JSON，随工作集交付。用高级配置填写了额外 `res://` 素材路径时，要一并向开发成员提供对应素材和路径约定。不要把浏览器截图当作可编辑源文件。

`editor/examples/Frontier.mapproject.json` 是完整关联示例。`FrontierImported.mapproject.json` 来自现有游戏大地图，其中原生营地的战场关联需要补充，因此可能出现待配置错误。

## 5. 常见问题

| 问题 | 处理 |
| --- | --- |
| 双击启动文件无反应 | 右键 `editor/index.html`，使用 Edge / Chrome 打开 |
| 素材不显示 | 确认完整解压、保留 editor/assets 目录；不要单独复制 HTML |
| 修改后刷新丢失 | 保存工作集后通过“打开”恢复；没有自动保存功能 |
| 无法修改参数 | 先切回“布局编辑”，输入后点“应用参数” |
| 缩小战场后报错 | 对象坐标不会自动缩放；按错误提示移回场内或撤销尺寸修改 |
| 没有生成文件 | 检查浏览器下载记录、保存对话框或下载权限 |
| 城镇不能打开真实 Godot 场景 | 独立版只预览编辑数据；将配置交回开发导入游戏工程 |

如浏览器对本地文件有限制，可让技术成员安装 Node.js 后运行 `node editor/tools/serve.cjs 8765`，访问 `http://127.0.0.1:8765/editor/index.html`。此为备用方式，普通地编无需安装。
