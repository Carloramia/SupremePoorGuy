# 事件配表工具

本地服务已启动时，使用 http://127.0.0.1:4186 或双击“打开本地服务配表工具.url”，正式导出可直接保存到工具目录。服务未启动时，在此目录运行 `node server.mjs`。全部脚本和Excel支持库均在本地，不需要额外安装依赖。

原来的“打开配表工具.cmd”仍直接打开 index.html，提供无需服务的离线编辑与浏览器下载，不负责后台启动进程。两种地址的浏览器草稿相互独立，迁移时先保存完整项目，再导入。

## 本地六事件内容（2026-10-07）

火速任命、旅途准备、图书馆开门日、防卫预算、血祭日、愿望的格式的原稿与节点草稿，已保存在工具自身的 `local-content.js` 中。直接打开 `index.html` 或使用本地服务都会读取，不再依赖 Codex 内置浏览器的数据。

首次读取这批内容时，仅补齐空原稿、未改动的内置原稿及纯占位节点。已经编辑的对白、节点、事件名、条件，以及新增的“时间陷阱”等其它事件都保留。补齐前的原浏览器项目保存在独立本机备份键 `supreme-poor-guy.event-editor.v1.before-content.six-events-20261007-v1`，不与逐次自动备份共用；本次补齐也可立即撤销。成功处理后只执行一次，后续刷新不恢复你主动删除的内容。

若某个事件存在冲突，点击顶部“本地六事件”：可只补齐空稿，或下载当前完整备份。需要采用本次录入稿时，先选择对应事件，再明确确认“替换当前事件为本地稿”；这只替换它的原稿、节点与备注，旧业务配置和其它事件不变，并会先保存完整本机备份。存储不可用则不进行强制替换。改过名或删除的事件不会自动重新创建。

本地内容是可修改草稿，不是已发布 JSON。“防卫预算”的任务进行中、完成回访入口暂时独立，等待阶段路由规范；条件与奖励备注不执行。各浏览器之后的修改仍然互不实时同步，正式发布仍需要验证与确认。

## 节点编排与验证（默认入口，2026-10-07）

现在默认进入“节点编排与验证”。从原情节稿建立顺序草稿，或导入 Godot 单事件 JSON，使用与 Godot 工作台一致的 **对白、选择、奖励、结束** 四类节点。原情节稿与旧七表配置保留，不自动覆盖。

流程：编排连接 → 校验结构 → 从起点逐分支预览 → 确认逻辑无误 → 导出当前事件 JSON。

- 点击流程卡直接修改说话人、正文、下一节点、选项去向及奖励明细。左键按住卡片任意正文位置即可自由上下／左右拖动，箭头和端口实时跟随。箭头才是实际执行关系，摆放位置不改变剧情顺序。
- 松手只记录一次撤销，位置自动保存到本机草稿、完整项目备份和 Excel；刷新仍保留。“自动排版”清除当前事件的手动位置，可撤销；“复位视角”只复位画布，不清除位置。Esc 取消本次拖动。单击仍编辑。
- 插入节点保留原后续。上/下移会调整真实连线，仅作用于连续单线的对白/奖励节点，不跨选择或汇合点。改节点 ID 会同步 start、next 和选项引用。
- 节点关系空白处左键拖动可上下／左右移动画布，中键也可拖动；“复位视角”复位。拖动画布不改变节点顺序或验证状态。
- 金色输出圆点拖到目标顶部入口（或目标卡片）即可改接；也支持先点输出再点输入。选择右侧编号圆点分别对应每个选项。空白处松手／Esc 取消，新循环与自身连接拒绝；箭头、表单及真实 next 同步。
- 断开既有逻辑线：点线后按“断开此连线”（或在线焦点处按 Delete），也可右键金色输出端口。右侧“下一节点”“选项去向”“进入此节点”均有明确的单条断开按钮。选择分支只断开对应编号的输出，不删除节点，不影响其它汇合连线；Ctrl+Z／撤销可恢复。断链允许保存草稿，但重新连接并验证前不能正式导出。拖线松到空白仍只取消本次拖线，不隐式断开旧线。
- 节点工具栏直接提供撤销／重做，支持正文、添加、删除、类型与连线操作；与底部历史共用最多80次当前页面快照，刷新后清空。输入框外 Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y，输入框内保留文本撤销。
- 缺正文、断链、重复选项、非法数量、循环会报错。孤立节点可保留在草稿，但必须连接或删除后才能导出正式文件。
- 预览保留同一窗口里的逐句记录，奖励只模拟确认。只有“从起点”完整走到结束并点击确认结束的路径才计入验证；“从选中节点”与中途停止不计入。
- 每个节点和每个选项都被完整路径覆盖后，点击“确认逻辑无误”才解锁导出。这不是穷举所有分支组合，也不能自动判断剧情好坏；人工确认仍然必要。
- 修改正文、奖励或连接使验证失效。验证记录只在当前页面会话保留，刷新或重新导入需重验。
- “保存完整项目”随时下载包含原稿、节点草稿和旧配置的备份，允许不完整草稿；浏览器自动保存不等于磁盘备份。
- Excel 会增加“节点编排”附表，保存节点 JSON、原稿备注和独立的编辑器布局 JSON；内容超过 Excel 单元格上限时拒绝导出，改用项目 JSON，避免截断。

**正式端口**：验证区导出的 `<事件ID>.event.json`，根字段为 `schema_version / id / title / start / reward_mode / nodes`。可直接由独立 Godot 工程的 `EventJsonPort` / `EventSession.play_file()` 读取。不含编辑器布局、原稿备注、验证记录或七张业务表。

通过本地服务使用时，点击正式导出会写入本工具 `output/events/`，显示准确绝对路径。文件名附时间与随机后缀，每次保存新文件，不覆盖既有 JSON；可直接在 Godot 文件面板加载。服务只监听 127.0.0.1，只接受本工具同源页面的明确导出，重新校验文件结构；不写原稿、不操作主游戏文件。直接打开 `index.html` 时仍通过浏览器下载；本地服务输出失败也可选择下载。

**项目备份**：`*.events.json` 用于重新打开配表工具，不能当作 Godot 单事件输入。“旧七表导出（非演示端口）”仅保留旧工作流，不供当前表现工程读取。

更多字段与职责边界见 [节点编排与验证规范](docs/节点编排与验证规范.md)。

如浏览器限制file页面本地存储，可在此目录运行 `node server.mjs`，访问 http://127.0.0.1:4186 。两种地址的浏览器草稿是独立的，通过保存/导入项目文件迁移。

## 使用流程

1. 从左侧选择或新建事件。
2. 在事件总览填写入口，新增阶段目标、剧情节点，再建立条件组和结果组。
3. 条件与结果ID在引用下拉框中选择；ID改名自动更新已知引用。
4. 检查配置，点击问题定位字段。草稿允许保留缺项，可发布事件必须补齐。
5. 保存项目为JSON备份；导出Excel后可重新导入；Godot JSON只包含可发布事件。

更改字段后离开输入框才提交。自动保存仅在当前浏览器当前地址生效，不等于磁盘备份。导入替换工作区前可以下载原项目，替换后支持撤销。复制事件会复制全部子配置并生成新ID。删除会提示，支持撤销。

## 数据格式与边界

- 项目文件：schema_version=1，name，tables，stories，flows，flow_notes，flow_layouts。flows 按事件 ID 保存单事件节点草稿，flow_notes 保存不执行的原稿备注；flow_layouts 按事件 ID、节点 ID 保存 `{x,y}` 编辑器坐标，兼容缺少这些字段的旧备份。布局不进入正式 Godot JSON，也不会使当前版本的预览覆盖与人工确认失效。
- Excel：字段说明与7类数据表；普通文本与公式开头的内容都作为文本写入，不执行用户表格中的公式。只读取xlsx现存值，不执行宏或外链。
- 旧剧情表：按事件名与台词转为草稿，玩家选项保留提示供人工转成分支。原稿奖励/效果/美术需求保留在事件总览；不自动解释自然语言执行动作。
- 旧七表输出：T_EVENTS等7张配置表，带schema_version。程序需要另行实现这些字段的加载、条件求值、事件推进和存档；不是当前独立 Godot 表现的输入。
- 示例怪物能力字段与地点ID须替换/绑定真实游戏数据。分批献祭与每只只计一项为建议，不代表游戏已实现。

模块：schema.js定义旧字段；model.js处理项目、旧引用与校验；flow.js处理节点关系、顺序、校验、预览与导出门槛（不依赖 DOM）；flow-editor.js处理流程图与编辑表单；xlsx.js处理离线Excel；app.js组合交互。布局不属于运行数据，奖励/地图/存档不属于编辑器。

运行全部数据测试：`npm test`；本地输出端口测试：`node tests/server-export.test.cjs`（临时使用4198端口）。`tests/flow.test.cjs` 还生成 Godot 互通测试样本，可在独立 Godot 工程运行 `--headless --script res://tests/validate_web_input.gd`。JSZip采用MIT/GPL双许可证，见vendor/LICENSE.markdown。
# 情节写作模式（2026-10-07）

通过“情节原稿”进入自由写作。选择左侧事件即可编辑事件名、概览、地点，以及按顺序排列的阶段、对话对象、正文、奖励、效果、需要内容。所有条件可先写自然语言，留空和待定内容不阻止保存。可添加、复制、删除、上下移动段落。

输入实时保存到当前浏览器。点击“保存情节项目”下载完整 JSON 备份；之后通过“导入”重新打开。自动保存不等于磁盘备份，换浏览器或清理数据前务必下载。不会写回原始 Excel。

支持新版九列事件稿（事件名、概览、地点、所处阶段、对话对象、内容、奖励、效果、需要内容）导入，包含事件首行的对话。导入会替换工作区，先保存备份。导出 Excel 新增“情节写作”表，同时保留原有七类结构化配置和字段说明，共九张表。

写作稿和结构化配置独立保存，不自动推断奖励、判定、跳转或 Godot 条件。旧配置保留在“结构化配置（后续整理）”入口；待剧情填写完成后再人工归纳规范。
